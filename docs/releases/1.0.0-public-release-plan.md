# Musicom 1.0.0 Public Release Plan

## Goal
Publish `musicom` 1.0.0 as a public, education-oriented library + Hermes-agent skill:
forward composition AND reverse analysis/decomposition, with a slimmed public corpus
and all private operational material moved to the Hermes-managed private repo/FS.

## Decisions (from user)
1. Scope: **slimmed research corpus** (not full dump, not version-bump-only).
2. Public corpus: **DBs + Instruments tree**, clarified as:
   - `projects/Styles/` stays **public** (educational compositions).
   - `projects/Production/` + rendered productions stay **private**.
   - Public is for education; per-piece productions inside Styles are examples
     (MIDI + small OGG + REPORT), not the full Production pipeline output.
3. Archive mechanism: **public/private repo split managed by Hermes agent**;
   archived material lives in the **private repo**, removed from the public tree
   (git history retains it). No `archive/` folder inside the public repo.
4. Skill framing: codebase runs **together with a Hermes agent** — publish it
   explicitly as a skill.
5. Docs: README currently forward-only → add **reverse analysis/decomposition**;
   add **simple examples** for composition + sound production/transformation;
   add a **manual for code agents (e.g. Claude)** on how to use code + MD files.

## Data flow (post-1.0.0)
- Forward: `compose()` / `UnitMatrixComposer` → `validate()` gate → MIDI +
  provenance → `produce(SP-001/SP-011/...)` → WAV → OGG.
- Reverse: MIDI/audio file → `analyze_midi()` (mido READ + harmony/set-theory +
  grid) → report (key, roman progression, Forte names, violations, density) →
  optional `project_to_score` (opt-in music21) for notation.
- Failure modes: stub `midifile_to_piece` (do not use — replaced by
  `analyze_midi`); `score_analyze` plotting (never call headless); empty MIDI
  (assert size >40B); unequal rows (pad via `_unit_from_events` pattern);
  missing SoundFont (use `discover_soundfont()`); musicpy/music21 eager import
  (keep lazy, pinned by `test_generator_lazy_imports`).
