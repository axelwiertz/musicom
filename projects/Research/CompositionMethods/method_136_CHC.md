## 1. The idea in one line

Every voice of the UnitMatrix is a *hailstone trajectory* — the orbit of an integer seed under the Collatz 3n+1 iteration — and the trajectory's own arithmetic (parity, altitude, stopping time, absorbing 4-2-1 cycle) is the composition: no dice, no corpus, no loss, only deterministic number theory.

## 2. The map

Non-shortcut form (Collatz 1937):

$$f(n)=\begin{cases}n/2 & n \equiv 0 \pmod 2,\\ 3n+1 & n \equiv 1 \pmod 2,\end{cases}$$

Shortcut ("accelerated") form — halves the step count, identical dynamics:

$$T(n)=\begin{cases}n/2 & n \equiv 0 \pmod 2,\\ \dfrac{3n+1}{2} & n \equiv 1 \pmod 2.\end{cases}$$

The conjecture (open; verified by computer for all $n \le 2.36\times10^{21}$) states every positive seed reaches the absorbing cycle $4\to2\to1$. The names: hailstone numbers (the values "rise and fall like hailstones in a cloud"), Syracuse problem (Hasse, 1950s), Kakutani's problem, Ulam's conjecture, wondrous numbers.

## 3. Mathematical structure that composition uses

### 3.1 Stopping times (the length grammar)
- **Total stopping time** $\sigma(n)$ = steps to 1 (OEIS A006577). $\sigma$ fixes the row length *before* any note exists: seed 27 → 111 steps (non-shortcut), 41 of them odd.
- **Record-holder seeds** (A006877): each has $\sigma$ greater than every smaller seed —
  $1,2,3,6,7,9,18,25,27,54,73,97,129,171,231,313,327,649,703,871,1161,2223,2463,2919,3711,6171,\ldots$ — a built-in ladder of ever-longer rows (macro-form: exposition on a short seed, climax on a record seed).
- Below $10^5$: record is 77031 at 350 steps; below $10^6$: 837799 at 524 steps; below $10^{12}$: 989345275647 at 1348 steps.
- **Powers of two** are the minimal rows: $\sigma(2^k)=k$, the trajectory never rises — the "bass line" option.

### 3.2 Parity vectors (the gesture grammar)
The parity sequence $p_i = a_i \bmod 2$ is exactly the sequence of operations. Foundational facts:
- $m,n$ share their first $k$ parity bits **iff** $m\equiv n \pmod{2^k}$ (Terras 1976; Everett 1977). Verified: residue $\bmod 2^6 \mapsto$ parity vector is a bijection (64/64 distinct).
- Every $n$ is uniquely identified by its full parity sequence; distinct cycles have distinct parity words.
- **Bohm–Sontacchi:** a periodic parity word of length $n$ with $m$ odd entries at $k_0<\cdots<k_{m-1}$ is generated by exactly one rational
$$\frac{3^{m-1}2^{k_0}+\cdots+3^0 2^{k_{m-1}}}{2^n - 3^m}.$$
The positive cycle's word "10" gives $1/(4-3)=1$ — the generator of $1\to2\to1$ (verified). Converse (Periodicity Conjecture): every rational with odd denominator has an eventually cyclic parity sequence.

### 3.3 The $2^k a + b$ algebra (provable voice-leading)
For the shortcut map: $T^k(2^k a + b) = 3^c a + d$, where $c$ = number of odd steps in the first $k$ and $d = T^k(b)$. Verified identities:
$$T^2(4a+1)=3a+1,\qquad T^4(16a+3)=9a+2,\qquad T^5(32a+1)=27a+2.$$
So a voice seeded $4a{+}1$ resolves to $3a{+}1$ in exactly two steps — a suspension resolved *by arithmetic*. Rows seeded in the same residue class $\bmod 2^k$ are a provable $k$-step canon.

### 3.4 Trunk merging (the tutti)
Trajectories coalesce: 54→27 (immediate), 97→73→…→47 joins the 27-trunk; seeds 27/54/73/97 all share shortcut peak **4616** and the same **4-2-1 tail** (verified). A multi-voice piece on record-holder seeds gets a *guaranteed* common climax and a *guaranteed* common closing cadence.

### 3.5 Cycles and undecidability (the boundaries)
- Known cycles: positive $1\to4\to2\to1$; negative $-1$, $-5$, $-17$. Eliahou (1993): any non-trivial cycle period is $p = 301994a + 17087915b + 85137581c$; Hercher (2023): no $m$-cycles with $m\le91$; best cycle-length bound 217 976 794 617 (2025).
- Conway (1972): generalized maps $g(n)=a_i n+b_i$ per residue $\pmod P$ (FRACTRAN) are undecidable; Kurtz–Simon: $\Pi^0_2$-complete even at $P=6480$. → For composition: 3n+1 itself is $O(1)$/step and terminates in practice; *generalizing* the map to encode grammar forfeits termination guarantees.

### 3.6 Growth heuristic
Considering only the odd values, each is on average $3/4$ of the previous one (geometric mean of ratios) — the classical argument for long-run descent; rigorously, the 2-adic extension has two division steps per multiplication step for almost all 2-adic seeds (Lagarias 1985).

## 4. Musical Elements Framework

| Element | Collatz source → musical role |
|---|---|
| **PITCH** | $a_n$ folded: register = bit-length $\lfloor\log_2 a_n\rfloor$ (altitude = registral arch; seed 27 spans 27→9232 ≈ 5 octaves), degree = $a_n \bmod |\text{scale}|$ (or pc = $a_n \bmod 12$); bias the fold so the tail residues (4,2,1) hit the tonic |
| **RHYTHM** | step = grid slot; parity = gesture class (even = short/quiet halving cell, odd = longer/louder multiplying cell); duration ∝ $\log_2 a_n$ sustains the peak; $\sigma(n)$ = row length; parity vector = the rhythmic score |
| **HARMONY** | congruent seeds ($\bmod 2^k$) = provable canons; $2^k a+b$ identities = exact prepared/resolved moves; trunk merging = common climax chord; 4-2-1 tail = universal closing chord |
| **STRUCTURE** | sections = trajectory segments cut at stopping-time milestones (climb / peak plateau / descent / 4-2-1 tail); macro-form = seed schedule (A006877 ladder); $\sigma$ fixes total length a priori, peak step fixes the climax position |
| **TEXTURE** | density = rows still in their climbing phase per section; peak rows loudest/longest; tail thins everything to a unison 4-2-1; record-peak seeds (A006884: 1,2,3,7,15,27,255,447,639,703,1819,…) = polyphonic hierarchy |

**Tonal gravity:** Moderate — the 4-2-1 tail is an unavoidable, provable HOME; the middle is wild. **Metric binding:** Grid-Locked / Continuous (step slots, fold-quantized). **Memory depth:** None — the state is the current integer. **Time complexity:** $\mathcal{O}(N)$ per trajectory (each step $O(1)$; bounded in practice by the verified range and modest stopping times).

## 5. UnitMatrix integration

- **Voices = rows = seeds.** Row $v$: seed $s_v$, one slot per step; hierarchy by seed size; per-voice child seed (`seed*101 + row`) for reproducibility.
- **Sections = columns = trajectory segments.** Governing seed's trajectory cut at milestones; early-finishing rows loop the 4-2-1 tail as an ostinato; every row ends on the section landmark (`section_len`) — zero drift preserved.
- **Cells = MusicUnit.** Per-section `MusicEvent` lists → `_unit_from_events(events, section_len)` → `fill_voice_section`; tail cells may be a chord unit on tail pcs.

## 6. Python implementation sketch

```python
"""generators/collatz_hailstone.py — candidate module for method 136 (CHC)."""
from dataclasses import dataclass, field
from typing import List, Tuple

from structures import MusicEvent
from workflows.musicom_workflow import _unit_from_events

def T(n: int) -> int:                      # shortcut map, O(1)
    return (3 * n + 1) // 2 if n % 2 else n // 2

@dataclass
class HailstoneTrajectory:
    seed: int
    values: List[int] = field(default_factory=list)   # a_0, a_1, ..., 1
    parity: List[int] = field(default_factory=list)   # 1 = multiply, 0 = halve

    @property
    def total_stopping_time(self) -> int:
        return len(self.values) - 1

    @property
    def peak(self) -> int:
        return max(self.values)

    @property
    def peak_step(self) -> int:
        return self.values.index(self.peak)

    def run(self, cap: int = 10_000) -> "HailstoneTrajectory":
        a = self.seed
        while a != 1 and len(self.values) < cap:
            self.values.append(a)
            self.parity.append(a % 2)
            a = T(a)
        self.values.append(1)
        return self

def record_holders(limit: int, step=T) -> List[int]:
    """A006877-style seeds: total stopping time greater than every smaller seed."""
    rec, best = [], -1
    for n in range(1, limit):
        s, a = 0, n
        while a != 1:
            a, s = step(a), s + 1
        if s > best:
            best, rec = s, rec + [n]
    return rec

def parity_bits(n: int, k: int, step=T) -> Tuple[int, ...]:
    bits = []
    for _ in range(k):
        bits.append(n % 2)
        n = step(n)
    return tuple(bits)

class CollatzPlan:
    """Fold trajectories into UnitMatrix cell events, zero-drift safe."""

    DEGREES = [0, 2, 4, 5, 7, 9, 11]      # C-major fold table

    def __init__(self, seeds: List[int], slots_per_section: int,
                 num_sections: int, step_ticks: int = 480, base: int = 36):
        self.seeds, self.sps, self.nsec = seeds, slots_per_section, num_sections
        self.step_ticks, self.base = step_ticks, base
        self.trajs = [HailstoneTrajectory(s).run() for s in seeds]

    def fold(self, a: int, voice: int) -> int:
        octave = (a.bit_length() - 1) // 3
        return min(120, self.base + 12 * voice + 12 * octave
                   + self.DEGREES[a % 7])

    def per_section_events(self, voice: int) -> List[List[MusicEvent]]:
        """Events grouped by section; each section must END at section_len."""
        traj = self.trajs[voice]
        sec = [[] for _ in range(self.nsec)]
        slot = 0
        for a in traj.values:
            sec_i = slot // self.sps
            if sec_i >= self.nsec:
                break
            start = (slot % self.sps) * self.step_ticks
            dur = self.step_ticks * (2 if a % 2 else 1)   # odd steps longer
            if start + dur > self.sps * self.step_ticks:
                dur = self.sps * self.step_ticks - start
            sec[sec_i].append(MusicEvent(self.fold(a, voice), 32 + 8 * (a.bit_length() - 1),
                                         start, start + dur))
            slot += dur // self.step_ticks
        while slot < self.nsec * self.sps:                # 4-2-1 tail ostinato
            sec_i, start = slot // self.sps, (slot % self.sps) * self.step_ticks
            dur = 2 * self.step_ticks
            if start + dur > self.sps * self.step_ticks:
                dur = self.sps * self.step_ticks - start
            sec[sec_i].append(MusicEvent(self.fold(4, voice), 40, start, start + dur))
            slot += dur // self.step_ticks
        return sec

    # consumer: per section s, per voice v -> _unit_from_events(sec[v][s],
    # section_len=sps*step_ticks) -> composer.fill_voice_section(...)
    # -> composer.validate() -> composer.to_midi(out)   (musicom spine)
```
