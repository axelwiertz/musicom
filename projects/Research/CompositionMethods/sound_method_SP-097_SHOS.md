## Overview

Sub-Harmonic Oscillator Synthesis (SHOS) generates the **undertone series** — frequencies at $f_0/n$ for integer divisors $n$ — from a single master oscillator running at the root pitch. Unlike the overtone series (harmonics at $n f_0$, used by additive, FM, and wavetable synthesis), the undertone series descends in pitch: $f_0, f_0/2, f_0/3, f_0/4, \dots$, producing octaves ($1/2$), twelfths ($1/3$), double octaves ($1/4$), and the full subharmonic chord stack.

Three distinct use cases:
1. **Subharmonic Bass Enhancement (Dbx 120-style)**: Detect fundamental from audio buffer → synthesize phase-locked $f_0/2$ → mix back. Club bass reinforcement.
2. **Subharmonic Chord Stacks (Moog Subharmonicon-style)**: Master oscillator at $f_0$ feeds parallel dividers with divisors $n \in \{1,2,3,4,5,6,\dots\}$, each producing phase-locked square/saw waves at $f_0/n$ mixed through independent level controls.
3. **Divide-Down Organ (Tonewheel approximation)**: A single high-frequency top-octave master is divided by successive ÷2 stages to generate all lower octaves.

The core distinction from every other synthesis method: **pitch relationship is division-based, not multiplication-based** — the spectrum descends from the fundamental rather than ascending, and all partials are locked to exact integer fractions of the master, creating a uniquely cohesive, monolithic, organ-like ensemble.

## Historical Lineage

- **Oskar Sala, Mixtur-Trautonium (1948–1952)**: First electronic instrument with a dedicated subharmonic generator. Produced up to 6 simultaneous subharmonic divisions from a single sawtooth master, controllable via touch-sensitive resistor-wire keyboard and formant bandpass filters. Used in Hitchcock's *The Birds* (1963) bird calls and hundreds of German film scores.
- **Dbx 100 "Boom Box" (1976) / Dbx 120A**: First commercial subharmonic enhancer for dance-club bass reinforcement. Extracts a synthetic sub-octave from recorded audio via zero-crossing frequency detection and modeled waveform synthesis.
- **Hammond Organ (1935) divide-down**: Uses 12 top-octave generators at the highest 12 semitones, each divided by flip-flop ÷2 stages to produce all lower octaves — a subharmonic approach for each tonewheel's pitch ratio.
- **Moog Subharmonicon (2020)**: Semi-modular analog synthesizer pairing a 6-voice subharmonic oscillator bank (divisors 1–6) with a 2×6-step polyrhythmic sequencer.

## Technical Mechanics

### 1. Analog Frequency Division (Flip-Flop Method)

A D-type flip-flop (CD4013) configured as a divide-by-2 toggle: the $Q$ output toggles on every rising edge of the clock input. With a square-wave input at $f_0$, the output is a 50% duty-cycle square wave at $f_0/2$. Cascading $m$ stages yields $f_0/2^m$. For arbitrary integer division by $n$, a synchronous counter resets when the count reaches $n$:

$$f_{\text{sub},n} = \frac{f_0}{n}, \quad n \in \mathbb{Z}^+$$

The output is always a square wave (rich odd harmonics: $n f_0$ for odd $n$) unless filtered.

### 2. Digital Phase-Accumulator Frequency Division

Given a master phase accumulator $\phi_m[n]$ with increment $\Delta_m = 2\pi f_0 / f_s$:

$$\phi_m[n+1] = \phi_m[n] + \Delta_m$$

A subharmonic at $f_0/n$ is generated by reading the master phase at a reduced rate:

$$\phi_n[n+1] = \phi_n[n] + \frac{\Delta_m}{n}$$

The subharmonic waveform is then $w(\phi_n)$ where $w$ is any waveform function (sine, saw, square, triangle, custom wavetable). This approach gives **arbitrary divisor $n$** and **arbitrary waveform shape**.

### 3. Phase-Locked Waveform Synthesis (Full Method)

Complete SHOS engine output as a weighted sum of $D$ subharmonic oscillators:

$$y[n] = \sum_{d=1}^{D} g_d \cdot w_d\left( \frac{\phi_m[n]}{d} \bmod 2\pi \right)$$

where $\mathcal{D}$ = active divisor set, $g_d$ = per-divisor gain, $w_d(\theta)$ = waveform.

### 4. Bass Enhancement Algorithm (Dbx-style)

1. Bandpass filter (40–120 Hz)
2. Detect $f_0$ via zero-crossing or autocorrelation
3. Synthesize sub-octave at $f_0/2$ from detected phase
4. Envelope match: $y_{\text{sub}}[n] = \sqrt{\frac{\text{RMS}_{\text{in}}}{\text{RMS}_{\text{sub}}}} \cdot y_{\text{sub}}^{\text{raw}}$
5. Mix: $y_{\text{out}} = x + \alpha \cdot y_{\text{sub}}$, $\alpha \in [0,1]$

### 5. Per-Divisor Pitch Detuning

Moog Subharmonicon-style fine detune of each subharmonic by $\pm\delta_d$ cents:

$$f_{\text{sub},d} = \frac{f_0}{d} \cdot 2^{\delta_d / 1200}$$

Breaking the perfect integer ratio produces beating, chorusing, and subtle harmonic movement.

### 6. Polyrhythmic Gating (Optional)

Each divisor $d$ has a gate that triggers every $d$ master metronome ticks:

$$\text{gate}_d[t] = \begin{cases}
1, & t \equiv 0 \pmod{d} \\
0, & \text{otherwise}
\end{cases}$$

Each subharmonic sounds only when $\text{gate}_d[t]=1$ — a complete polyrhythmic sequencer.

### 7. Computational Cost

**Per-sample cost**: $O(D)$ where $D = |\mathcal{D}|$. For 6 divisors with wavetable lookup: 6 reads + 6 multiplies + 1 sum ≈ **13 operations per sample** — among the cheapest polyphonic synthesis methods.

## Musical Elements Framework

| Element | Contribution |
|---------|-------------|
| **PITCH** | Master tracks MIDI key ($f_0 = 440 \cdot 2^{(k-69)/12}$). Divisor $d$ produces $f_0/d$: $d=2$ = P8 below, $d=3$ = P12 below, $d=4$ = 2×P8 below, $d=5$ = M17 below, $d=6$ = P19 below. Active divisor set selects chord voicing from single root. |
| **RHYTHM** | Master gate provides articulation. Polyrhythmic gate extension ($\S6$) provides independent patterns per divisor — complete polyrhythmic engine. Shared envelope = rhythmic compression (all divisors attack together). |
| **HARMONY** | Divisors {1,2,3,4,5,6} produce root, P8, P12, 2×P8, M17, P19 — a maj13$^{\text{(omit11)}}$ from one note. Changing root = harmonic planing. Detuning morphs exact to tempered. |
| **STRUCTURE** | Per-section divisor sets $\mathcal{D}_s$ define macro-form: intro={1,2}, verse={1,2,3,4}, chorus={1,2,3,4,5,6}, bridge={2,3}, outro={1}. Detuning $\delta_d(s)$ and gate patterns $G_d(s)$ add dimensions. |
| **TEXTURE** | Density scales with $|\mathcal{D}|$ — 6 divisors from single note = very dense. Waveform type shapes character: all-saw=bright, all-sine=soft organ. Per-divisor detuning = chorus-thickening. |

## Python Implementation Sketch

```python
import numpy as np

def shos_synthesize(pitch_hz, sample_rate=44100, duration_s=1.0,
                    divisors=None, gains=None, detune_cents=None,
                    master_wave="saw", sub_wave="saw",
                    adsr_ms=(10, 50, 0.5, 100)):
    """Generate N samples of subharmonic oscillator stack."""
    if divisors is None:
        divisors = [1, 2, 3, 4, 5, 6]
    D = len(divisors)
    if gains is None:
        gains = [1.0/D] * D
    if detune_cents is None:
        detune_cents = [0.0] * D

    num_samples = int(sample_rate * duration_s)
    output = np.zeros(num_samples)
    phi_m = 0.0
    delta_m = 2 * np.pi * pitch_hz / sample_rate
    detune_factors = [2**(dc/1200) for dc in detune_cents]

    # Wavetables
    wt_size = 2048
    wt_map = {
        "saw": np.linspace(-1, 1, wt_size, endpoint=False),
        "sine": np.sin(np.linspace(0, 2*np.pi, wt_size, endpoint=False)),
        "square": np.where(np.linspace(-1, 1, wt_size, endpoint=False) >= 0, 1, -1),
    }

    # ADSR envelope
    a_len, d_len, s_level, r_len = [int(x*sample_rate/1000) for x in (adsr_ms[0], adsr_ms[1], 0, adsr_ms[3])]
    env = np.ones(num_samples)
    if a_len > 0:
        env[:a_len] = np.linspace(0, 1, a_len)
    if d_len > 0:
        env[a_len:a_len+d_len] = np.linspace(1, s_level, d_len)
    sustain_end = num_samples - r_len
    if sustain_end > a_len + d_len:
        env[a_len+d_len:sustain_end] = s_level
    if r_len > 0:
        env[sustain_end:] = s_level * np.linspace(1, 0, r_len)

    master_tbl = wt_map.get(master_wave, wt_map["saw"])
    sub_tbl = wt_map.get(sub_wave, wt_map["saw"])

    for n in range(num_samples):
        sample = 0.0
        for d_idx, d in enumerate(divisors):
            phi_sub = phi_m / d % (2*np.pi)
            tbl = master_tbl if d == 1 else sub_tbl
            wave_val = tbl[int((phi_sub/(2*np.pi)) % 1.0 * wt_size)]
            sample += gains[d_idx] * wave_val
        output[n] = sample * env[n]
        phi_m = (phi_m + delta_m) % (2*np.pi)

    # Normalize
    peak = np.max(np.abs(output))
    if peak > 1e-8:
        output = output / peak * 0.95
    return output
```
