# Method 101 — Flow Matching Composition (FMC)

**ID**: 101
**Paradigm**: AI-Driven
**Layer**: concrete
**Acronym**: FMC

## One-line Description

Vector-field regression (Conditional Flow Matching) on symbolic music token embeddings: deterministic ODE integration pushes Gaussian noise → structured, multi-voice, multi-section token sequences for UnitMatrix cell filling.

## Extended Mathematical Description

### 1. Probability Paths and Flows

Let $p_0(x)$ be a simple prior distribution (standard Gaussian $\mathcal{N}(0, I)$) and $p_1(x)$ be the data distribution (symbolic music token sequences). A **probability path** $p_t(x)$ for $t \in [0, 1]$ interpolates between them. The **flow** is a time-dependent diffeomorphism $\psi_t : \mathbb{R}^d \to \mathbb{R}^d$ such that $p_t = [\psi_t]_* p_0$ (pushforward), generated by a **vector field** $u_t$:

$$\frac{d}{dt} \psi_t(x) = u_t(\psi_t(x)), \quad \psi_0(x) = x$$

The time-evolution of the density follows the **continuity equation**:

$$\partial_t p_t + \nabla \cdot (p_t u_t) = 0$$

### 2. Conditional Flow Matching (CFM) Objective

Rather than solving for $u_t$ directly (intractable for complex $p_1$), we define **conditional** probability paths $p_t(x \mid x_1)$ per data point $x_1$:

$$p_t(x) = \int p_1(x_1) \cdot p_t(x \mid x_1) \, dx_1$$

with the **optimal transport (OT) path**:

$$p_t(x \mid x_1) = \mathcal{N}(x \mid (1-t)x_0 + t x_1, \, \sigma_{\min}^2)$$

where $x_0 \sim p_0$ and the noise variance $\sigma_{\min} \approx 0$ for deterministic flows. The **conditional vector field** is:

$$u_t(x \mid x_1) = \frac{x_1 - x_0}{1 - t} = x_1 - x_0$$

The CFM loss directly regresses a neural network $v_\theta(t, x)$ onto this conditional target:

$$\mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t \sim \mathcal{U}[0,1], \, x_0 \sim p_0, \, x_1 \sim p_1} \left\| v_\theta(t, x_t) - (x_1 - x_0) \right\|^2$$

where $x_t = (1-t)x_0 + t x_1$. This loss is:
- **Simulation-free**: no ODE integration during training (unlike CNF maximum-likelihood)
- **Architecture-free**: $v_\theta$ can be any NN (transformer, UNet, MLP-mixer)
- **Valid**: $\nabla_\theta \mathcal{L}_{\text{CFM}} = \nabla_\theta \mathcal{L}_{\text{FM}}$ (marginal vector field gradient equality, Lipman Thm. 1)

### 3. Sampling (Generation)

Sample $x_0 \sim \mathcal{N}(0, I)$, then integrate the ODE:

$$x(1) = x_0 + \int_0^1 v_\theta(t, x(t)) \, dt$$

Using a numerical ODE solver (Euler: $x_{t+\Delta t} = x_t + \Delta t \cdot v_\theta(t, x_t)$; RK4; Dormand-Prince). The final $x(1)$ is the generated token embedding vector.

### 4. Discrete Extension via Embedding

For symbolic music tokens $s \in \mathcal{V}$ (vocabulary of MIDI pitch/duration/velocity/offset tokens), define an embedding matrix $E \in \mathbb{R}^{|\mathcal{V}| \times d}$ and map:

$$x_1 = E[s_1; s_2; \ldots; s_L] \in \mathbb{R}^{L \cdot d}$$

After sampling $x(1)$, decode via:

$$s_i = \arg\max_{v \in \mathcal{V}} \left( W \cdot x(1)_{i} \right)_v$$

or via a learned MLP decoder. Alternatively, **Discrete Flow Matching** (Campbell et al., 2024) operates directly on the simplex:

$$x_t = (1-t) \cdot e_{x_0} + t \cdot e_{x_1}, \quad e_x \in \Delta^{|\mathcal{V}|-1}$$

with a cross-entropy regression loss.

### 5. Cascaded Architecture (MusicFlow)

Two-stage flow matching for conditioning/control:
1. **Prior FM**: $v_\phi(t, z)$ maps text/section-embedding → semantic latent $z(1)$
2. **Decoder FM**: $v_\theta(t, x \mid c)$ maps $x_0$ → $x(1)$ conditioned on $c = \text{Proj}(z(1)) + \text{section-embedding}$

Both flows are trained independently with the CFM objective. The cascade enables text→semantics→tokens without requiring aligned (text, MIDI) pairs — the prior is trained on (text, semantic embedding) and the decoder on (semantic embedding, MIDI).

## Python Implementation Sketch

```python
"""
Flow Matching Composition (FMC) — Python implementation sketch.

Requires: torch, einops, numpy
Trains and samples a Conditional Flow Matching model for symbolic music.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
from typing import Optional, List

# ---------------------------------------------------------------------------
# 1. Conditional Flow Matching (CFM) Loss
# ---------------------------------------------------------------------------

def cfm_loss(
    v_theta: nn.Module,
    x_0: torch.Tensor,       # noise: [B, L*d] or [B, L, d]
    x_1: torch.Tensor,       # data: [B, L*d] or [B, L, d]
    t: torch.Tensor,         # time: [B, 1]
) -> torch.Tensor:
    """
    Conditional Flow Matching loss.

    CFM loss = E_{t, x_0, x_1} [ || v_theta(t, x_t) - (x_1 - x_0) ||^2 ]

    where x_t = (1-t)*x_0 + t*x_1  (optimal transport path).
    """
    # Linear interpolation (OT path)
    x_t = (1.0 - t) * x_0 + t * x_1          # [B, L*d]
    target = x_1 - x_0                        # target vector field [B, L*d]

    # Predicted vector field
    v_pred = v_theta(t.squeeze(-1), x_t)      # [B, L*d]

    # MSE loss
    loss = F.mse_loss(v_pred, target)
    return loss


# ---------------------------------------------------------------------------
# 2. Transformer-based vector field network
# ---------------------------------------------------------------------------

class MusicFlowTransformer(nn.Module):
    """
    v_theta(t, x) — a transformer that takes time t and the current
    interpolation state x_t, and outputs the predicted velocity.

    For symbolic music, the input x_t is a concatenation of per-token
    embeddings (pitch + duration + position + voice-ID).
    """

    def __init__(
        self,
        vocab_size: int = 128,   # MIDI pitch + special tokens
        d_model: int = 256,
        n_heads: int = 8,
        n_layers: int = 6,
        max_seq_len: int = 2048,
        num_voices: int = 4,
    ):
        super().__init__()
        self.d_model = d_model
        self.num_voices = num_voices

        # Token embedding (pitch, duration, offset, etc.)
        self.token_embed = nn.Embedding(vocab_size, d_model)
        # Voice embedding (added to token embedding for voice identity)
        self.voice_embed = nn.Embedding(num_voices, d_model)
        # Position encoding
        self.pos_embed = nn.Embedding(max_seq_len, d_model)

        # Time conditioning (FiLM-style)
        self.time_mlp = nn.Sequential(
            nn.Linear(1, d_model),
            nn.SiLU(),
            nn.Linear(d_model, d_model),
        )

        # Transformer backbone
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=n_heads,
            dim_feedforward=4 * d_model,
            dropout=0.1,
            activation='gelu',
            batch_first=True,
        )
        self.transformer = nn.TransformerEncoder(
            encoder_layer, num_layers=n_layers
        )

        # Output projection to velocity (same dim as input)
        self.output_proj = nn.Linear(d_model, d_model)

    def forward(
        self,
        t: torch.Tensor,                # [B]
        x_t: torch.Tensor,              # [B, L*d_model]  (already embedded)
        voice_ids: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        """
        Predict velocity v_theta(t, x_t).

        Args:
            t: times in [0,1], shape [B]
            x_t: current interpolated token embeddings, shape [B, L, d_model]
            voice_ids: per-token voice assignments [B, L]

        Returns:
            velocity field, shape [B, L, d_model]
        """
        B, L, d = x_t.shape

        # Position encoding
        pos = torch.arange(L, device=x_t.device).unsqueeze(0).expand(B, -1)
        x = x_t + self.pos_embed(pos)

        # Voice embedding
        if voice_ids is not None:
            x = x + self.voice_embed(voice_ids)

        # Time conditioning (add to all tokens)
        t_emb = self.time_mlp(t.unsqueeze(-1)).unsqueeze(1)  # [B, 1, d]
        x = x + t_emb

        # Transformer encoder
        h = self.transformer(x)  # [B, L, d]

        # Project to velocity
        v = self.output_proj(h)  # [B, L, d]
        return v


# ---------------------------------------------------------------------------
# 3. ODE Sampling (Euler)
# ---------------------------------------------------------------------------

def sample_flow(
    v_theta: nn.Module,
    n_sequences: int,
    seq_len: int,
    d_model: int,
    num_voices: int,
    device: str = 'cpu',
    n_steps: int = 100,
    voice_ids: Optional[torch.Tensor] = None,
) -> torch.Tensor:
    """
    Sample from the flow model via Euler ODE integration.

    Args:
        v_theta: trained vector field network
        n_sequences: batch size
        seq_len: sequence length (in tokens)
        d_model: embedding dimension
        num_voices: number of voices (for voice assignment)
        n_steps: ODE integration steps (default 100)
        voice_ids: voice ID for each token [n_sequences, seq_len]

    Returns:
        x_1: generated token embeddings [B, L, d_model]
    """
    # Start from Gaussian noise
    x_t = torch.randn(n_sequences, seq_len, d_model, device=device)

    dt = 1.0 / n_steps
    for i in range(n_steps):
        t = torch.full((n_sequences,), i * dt, device=device)
        v = v_theta(t, x_t, voice_ids=voice_ids)
        x_t = x_t + dt * v  # Euler step

    return x_t  # x_1


# ---------------------------------------------------------------------------
# 4. Training Loop
# ---------------------------------------------------------------------------

def train_cfm(
    model: nn.Module,
    dataloader: torch.utils.data.DataLoader,
    n_epochs: int = 100,
    lr: float = 1e-4,
    device: str = 'cpu',
):
    """
    Train the flow matching model with the CFM loss.

    Each batch: x_1 = token embeddings from dataset
                 x_0 = Gaussian noise
                 t   = uniform [0,1]
    """
    optimizer = torch.optim.AdamW(model.parameters(), lr=lr)

    for epoch in range(n_epochs):
        total_loss = 0.0
        for batch in dataloader:
            # batch['token_embeds']: [B, L, d] — the data
            x_1 = batch['token_embeds'].to(device)
            B = x_1.shape[0]

            # Sample noise and time
            x_0 = torch.randn_like(x_1)
            t = torch.rand(B, 1, device=device)

            # CFM loss
            loss = cfm_loss(model, x_0, x_1, t)

            optimizer.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()

            total_loss += loss.item()

        avg_loss = total_loss / len(dataloader)
        print(f"Epoch {epoch+1}/{n_epochs}  Loss: {avg_loss:.4f}")


# ---------------------------------------------------------------------------
# 5. Decoding to MIDI Notes
# ---------------------------------------------------------------------------

def decode_to_notes(
    x_1: torch.Tensor,
    token_decoder: nn.Module,
    voice_boundaries: List[int],
) -> List[List[dict]]:
    """
    Decode generated embeddings back to per-voice note sequences.

    Args:
        x_1: [1, L, d] generated embeddings
        token_decoder: maps embedding → token class
        voice_boundaries: token index boundaries per voice

    Returns:
        per_voice_notes: list of lists of dicts {pitch, velocity, start, end}
    """
    # Decode each token position
    logits = token_decoder(x_1[0])  # [L, vocab_size]
    token_ids = logits.argmax(dim=-1).cpu().numpy()  # [L]

    # Parse into per-voice note events (REMI-style time-shift decoding)
    # ... (token stream parsing logic)

    notes = []
    for v_idx in range(len(voice_boundaries) - 1):
        start, end = voice_boundaries[v_idx], voice_boundaries[v_idx + 1]
        voice_tokens = token_ids[start:end]
        # Parse token stream into note events
        voice_notes = _parse_remi_stream(voice_tokens, v_idx)
        notes.append(voice_notes)

    return notes


def _parse_remi_stream(tokens, voice_id):
    """Parse a REMI-style token sequence into MusicEvent-like dicts."""
    events = []
    current_time = 0.0
    current_pitch = None
    current_velocity = None

    for token in tokens:
        # Simplified token decoding — full REMI has type-byte prefix
        if token < 128:  # Note-on
            if current_pitch is not None:
                events.append({
                    'pitch': current_pitch,
                    'velocity': current_velocity,
                    'start_tick': int(current_time),
                    'end_tick': int(current_time + 240),  # default 1/4 note
                    'voice': voice_id,
                })
            current_pitch = token
            current_velocity = 80
        elif 128 <= token < 144:  # Time-shift (16ths)
            current_time += (token - 127) * 30  # ticks per 16th
        # ... (expand for full REMI vocabulary)

    if current_pitch is not None:
        events.append({
            'pitch': current_pitch,
            'velocity': current_velocity,
            'start_tick': int(current_time),
            'end_tick': int(current_time + 240),
            'voice': voice_id,
        })
    return events

# Usage Example
# ---------------------------------------------------------------------------

if __name__ == '__main__':
    # Model setup
    model = MusicFlowTransformer(
        vocab_size=128 + 16,   # MIDI notes + special tokens
        d_model=256,
        n_heads=8,
        n_layers=6,
        max_seq_len=2048,
        num_voices=4,
    )

    # Dummy data: [B=4, L=256, d=256]
    dummy_x_1 = torch.randn(4, 256, 256)
    dummy_voice_ids = torch.randint(0, 4, (4, 256))

    # Test CFM loss
    x_0 = torch.randn_like(dummy_x_1)
    t = torch.rand(4, 1)
    loss = cfm_loss(model, x_0, dummy_x_1, t)
    print(f"Test CFM loss: {loss.item():.4f}")

    with torch.no_grad():
        sample = sample_flow(

        )
        print(f"Sample shape: {sample.shape}")  # [1, 256, 256]
```
