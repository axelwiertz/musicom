

# Quantum Walk Composition (QWC) (Method 052)

### **Source**
Adapted from quantum information science: continuous-time quantum walks (CTQW) on graphs, pioneered by Farhi & Gutmann (1998, "Quantum Mechanical Computers Near the Heisenberg Bound", Physical Review A) and discrete-time quantum walks (DTQW) by Aharonov et al. (1993) and Ambainis et al. (2001). Musical applications draw on the analogy between quantum probability amplitudes and musical transition systems: nodes = pitch classes/chords, edges = allowed transitions, unitary evolution = compositional process. Key references: Portugal (2019) "Stochastic Methods in Quantum Walks"; Childs et al. (2003) "Exponential algorithmic speedup by quantum walk"; and the emerging field of quantum-inspired generative art (Marszałek et al., 2022). This formulation extends classical random walk methods (002 Markov, 041 ACOPF) by exploiting quantum interference — paths can constructively or destructively interfere, producing genuinely non-classical probability distributions over musical states.

### **Description**
Quantum Walk Composition (QWC) generates musical material by simulating quantum walks on graphs whose nodes represent musical objects (pitch classes, chords, scale degrees, or rhythmic states). Unlike classical random walks (Markov chains), quantum walks evolve via **unitary operators** that preserve superposition and allow **quantum interference** between alternative paths. The result is a probability distribution over musical states that exhibits non-classical features: ballistic spreading (quadratically faster than classical diffusion), periodic revivals (probability returning to the initial node), and localization phenomena (probability trapped near defects).

The method operates in two modes:

**Continuous-Time Quantum Walk (CTQW)**: The system evolves under the Schrödinger equation $|\psi(t)\rangle = e^{-iHt}|\psi(0)\rangle$, where $H$ is the graph Hamiltonian (typically the adjacency matrix $A$ or Laplacian $L$). The probability of finding the walker at node $j$ at time $t$ is $p_j(t) = |\langle j | \psi(t) \rangle|^2$. Musical events are generated by **measuring** the quantum state at discrete time steps — each measurement collapses the superposition to a single node (pitch/chord) sampled from the probability distribution.

**Discrete-Time Quantum Walk (DTQW)**: Uses a **coin operator** $C$ (typically a Hadamard or Grover diffusion gate) that creates superposition over edge directions, followed by a **shift operator** $S$ that moves the walker along edges conditioned on the coin state. One step = $U = S \cdot (C \otimes I)$. The coin space adds an internal degree of freedom, enabling richer interference patterns and chiral transport (directional bias).

**Multi-Walker Extension**: Multiple quantum walkers can be **entangled** — their joint state cannot be factored into independent single-walker states. Measuring entangled walkers produces **correlated** musical events: if walker 1 collapses to node $A$, walker 2's distribution instantaneously updates. This generates chord voicings with quantum correlations that have no classical analog.

### **Musical Elements Framework**
- **PITCH**: Graph nodes = pitch classes (0-11) or scale degrees. The quantum walk probability amplitude $|\psi(t)\rangle$ at each node determines pitch selection probability upon measurement: $p_j(t) = |\langle j | \psi(t) \rangle|^2$. Key quantum effects:
  - **Ballistic spreading**: After $T$ steps, probability spreads to $\mathcal{O}(T)$ nodes (vs. $\mathcal{O}(\sqrt{T})$ for classical). Melodic range expands rapidly.
  - **Revival**: On cycle graphs $C_n$, probability periodically returns to the starting node with period $T_{rev} = n$ (for CTQW). Creates natural phrase repetition.
  - **Localization**: Defects in the graph (missing edges, weighted anomalies) trap probability, creating pitch centers or recurring motifs.
- **RHYTHM**: Time steps of the quantum walk map to rhythmic subdivisions (e.g., 16th notes). Measurement events at each step trigger notes when $p_j(t) > \theta$ (threshold). Quantum revival cycles create natural rhythmic periods. The **return probability** $P_{return}(t) = |\langle \psi(0) | \psi(t) \rangle|^2$ governs rhythmic density: high return probability = sparse, pulse-like rhythm; low return probability = dense, flowing rhythm.
- **HARMONY**: Multi-walker quantum walks generate **entangled chord voicings**. If walkers are prepared in a Bell state $|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$, measuring walker 1 at pitch $p_1$ instantly constrains walker 2 to pitch $p_2$ with quantum correlation. The **entanglement entropy** $S = -\text{Tr}(\rho_A \log \rho_A)$ of the reduced density matrix $\rho_A$ measures voice independence: $S = 0$ = block chords (fully correlated), $S > 0$ = contrapuntal independence. Harmonic tension = deviation from maximally entangled state.
- **STRUCTURE**: Graph topology determines macro-form. Different graph families produce different structural archetypes:
  - **Cycle graph $C_n$**: Periodic, rondo-like form (revival every $n$ steps).
  - **Complete graph $K_n$**: Through-composed, uniform exploration (no preferred node).
  - **Star graph $S_n$**: Central pivot with radiating branches (verse-chorus with tonic center).
  - **Hypercube $Q_d$**: High-dimensional, fractal-like exploration (complex, non-repeating form).
  Section changes = graph topology changes (e.g., $C_{12} \to K_7 \to S_5$ for A-B-A form).
- **TEXTURE**: Number of quantum walkers = polyphonic density. Single walker = monophony. Multiple independent walkers = homophony (simultaneous but uncorrelated). Multiple entangled walkers = complex polyphony with quantum correlations. Texture evolves by changing walker count and entanglement structure per section.

### **UnitMatrix Integration (Voices & Sections)**
- **Rows (Voices)**: Each voice $v$ = one quantum walker (or one measurement channel of a multi-walker system). Voice 1 = walker 1, Voice 2 = walker 2, etc. For entangled walkers, voices share a joint quantum state but are measured independently.
- **Columns (Sections)**: Each section $s$ = a different graph topology $G_s$ or Hamiltonian parameter set $H_s$. Section A uses graph $G_A$ (e.g., cycle $C_{12}$ for periodic form), Section B uses $G_B$ (e.g., complete $K_7$ for through-composed), Section C returns to $G_A$ (ABA form).
- **Cells**: Each cell $U_{v, s}$ contains:
  - `{PITCH}`: Measurement outcome $j_v$ sampled from $p_j^{(v)}(t) = |\langle j | \psi^{(v)}(t) \rangle|^2$ at the time step corresponding to cell $(v, s)$. For entangled walkers, joint measurement collapses the multi-walker state.
  - `{RHYTHM}`: Onset trigger if $p_j^{(v)}(t) > \theta$ (threshold). Rhythmic density = fraction of time steps above threshold.
  - `{TEXTURE}`: Entanglement entropy $S^{(v)}$ of voice $v$'s reduced density matrix. High $S$ = independent counterpoint; low $S$ = correlated block movement.
- **Mapping Flow**:
  1. Define graph topology $G_s$ and Hamiltonian $H_s$ for each section $s$.
  2. Initialize quantum state $|\psi(0)\rangle$ (e.g., localized at tonic node, or uniform superposition).
  3. Evolve state: $|\psi(t)\rangle = e^{-iH_s t}|\psi(0)\rangle$ (CTQW) or apply discrete steps $U^t$ (DTQW).
  4. At each time step $t$ corresponding to a rhythmic subdivision, measure the state to obtain pitch $j_v$ for voice $v$.
  5. For multi-walker systems, prepare entangled initial state (e.g., Bell state) and measure joint state.
  6. Compute entanglement entropy $S^{(v)}$ per voice for texture metadata.
  7. Quantize measured pitches to scale/chord tones (Phase 2 of musicom workflow).
  8. Fill UnitMatrix cells with pitches, rhythmic triggers, and texture coefficients.

### **Pitfalls**
1. **Measurement collapse destroys superposition**: Once measured, the quantum state collapses. To generate multiple events, either re-prepare the initial state or use continuous measurement (weak measurement) that partially collapses.
2. **Revival period mismatch**: On cycle graphs, revival period $T_{rev} = n$ may not align with musical phrase length. Adjust graph size $n$ to match desired phrase structure (e.g., $n = 16$ for 16-beat phrases).
3. **Entanglement decoherence**: In multi-walker systems, environmental noise (simulated or real) destroys entanglement. For composition, this is a feature: gradually increasing decoherence = transition from entangled polyphony to independent voices.
4. **Graph topology discontinuity**: Switching graph topology between sections ($G_A \to G_B$) can produce discontinuous probability distributions. Smooth transitions via adiabatic evolution: slowly morph $H(t) = (1-t)H_A + t H_B$ over a transition window.
5. **Computational cost**: Simulating $N$-walker quantum walks requires $\mathcal{O}(d^N)$ state vector size (where $d$ = graph dimension). For $N > 4$ walkers, use tensor network methods (MPS/MPO) to compress the state.
6. **Pitch quantization artifacts**: Quantum walk produces continuous probability distributions; quantizing to discrete scale degrees can introduce bias. Use inverse CDF sampling to preserve the quantum probability structure.
7. **Phase ambiguity**: Quantum states are defined up to global phase $e^{i\phi}$. For composition, global phase is irrelevant (probabilities unchanged), but relative phase between walkers matters for interference.
8. **Localization vs. exploration trade-off**: Defects in the graph create localization (pitch centers) but reduce exploration. Balance by tuning defect strength (edge weight anomaly) to control motif recurrence vs. novelty.
9. **DTQW coin bias**: The coin operator $C$ determines directional bias. Hadamard coin = unbiased; biased coins (e.g., $C = \text{diag}(\sqrt{p}, \sqrt{1-p})$) create chiral transport (melodic directionality).
10. **Temporal coherence**: For long compositions, quantum state must be evolved coherently across sections. If section boundaries are hard (abrupt $H$ change), phase coherence breaks. Use soft boundaries (adiabatic morphing) or re-prepare state at section starts.

### **Implementation Requirements (Python / NumPy / SciPy)**
```python
import numpy as np
from scipy.linalg import expm

def ctqw_evolve(adjacency_matrix, initial_state, time_steps, dt=0.1):
    """
    Continuous-time quantum walk on a graph.
    adjacency_matrix: (n, n) graph adjacency matrix (Hamiltonian H).
    initial_state: (n,) complex vector |ψ(0)⟩.
    time_steps: number of evolution steps.
    dt: time increment per step.
    Returns: (time_steps, n) array of probabilities p_j(t).
    """
    n = adjacency_matrix.shape[0]
    H = adjacency_matrix  # Hamiltonian = adjacency matrix
    psi = initial_state.astype(complex)
    probs = np.zeros((time_steps, n))
    
    for t in range(time_steps):
        # Measure probability distribution
        probs[t] = np.abs(psi)**2
        # Evolve: |ψ(t+dt)⟩ = exp(-iH dt)|ψ(t)⟩
        U = expm(-1j * H * dt)
        psi = U @ psi
    
    return probs

def dtqw_step(state, coin_operator, shift_operator):
    """
    Discrete-time quantum walk: one step = shift ∘ coin.
    state: (n, d) array where n = nodes, d = coin dimension.
    coin_operator: (d, d) unitary (e.g., Hadamard).
    shift_operator: function that moves walker along edges.
    Returns: updated state.
    """
    # Apply coin to internal degree of freedom
    state = np.einsum('ij,nj->ni', coin_operator, state)
    # Apply shift (moves walker along edges conditioned on coin state)
    state = shift_operator(state)
    return state

def measure_pitch(probabilities, scale_degrees, threshold=0.05):
    """
    Sample a pitch from quantum walk probability distribution.
    probabilities: (n,) array of probabilities p_j.
    scale_degrees: (n,) array of MIDI pitch numbers.
    threshold: minimum probability to trigger event.
    Returns: (pitch, triggered) tuple.
    """
    if np.max(probabilities) < threshold:
        return None, False
    # Sample from distribution
    pitch_idx = np.random.choice(len(probabilities), p=probabilities)
    return scale_degrees[pitch_idx], True

def bell_state_entanglement(n_nodes):
    """
    Prepare two walkers in a Bell state (maximally entangled).
    Returns: (n_nodes^2,) complex vector |Φ⁺⟩ = (|00⟩ + |11⟩)/√2.
    """
    state = np.zeros(n_nodes**2, dtype=complex)
    for i in range(n_nodes):
        state[i * n_nodes + i] = 1.0 / np.sqrt(n_nodes)
    return state

def entanglement_entropy(state, n_nodes):
    """
    Compute von Neumann entanglement entropy of bipartite state.
    state: (n_nodes^2,) complex vector.
    Returns: scalar entropy S.
    """
    # Reshape to density matrix
    rho = np.outer(state, state.conj()).reshape(n_nodes, n_nodes, n_nodes, n_nodes)
    # Trace out second walker
    rho_A = np.trace(rho, axis1=1, axis2=3)
    # Compute eigenvalues
    eigenvalues = np.linalg.eigvalsh(rho_A)
    eigenvalues = eigenvalues[eigenvalues > 1e-10]  # filter zeros
    # Von Neumann entropy
    S = -np.sum(eigenvalues * np.log(eigenvalues))
    return S

# Example: CTQW on a 12-node cycle graph (chromatic pitch classes)
n = 12
adj = np.zeros((n, n))
for i in range(n):
    adj[i, (i+1) % n] = 1  # cycle edges
    adj[i, (i-1) % n] = 1

# Initial state: localized at tonic (C = 0)
psi_0 = np.zeros(n, dtype=complex)
psi_0[0] = 1.0

# Evolve for 64 time steps
probs = ctqw_evolve(adj, psi_0, time_steps=64, dt=0.5)

# Measure pitches at each step
scale_degrees = np.arange(60, 72)  # MIDI C4 to B4
pitches = []
for t in range(64):
    pitch, triggered = measure_pitch(probs[t], scale_degrees, threshold=0.05)
    if triggered:
        pitches.append(pitch)
```
