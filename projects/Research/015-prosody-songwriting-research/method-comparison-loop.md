# Method Comparison Loop

## Idea
Do not pick one method blind. Run several methods, compare outputs, then select best one.

## Loop
1. Pick source.
2. Choose 2-4 candidate methods.
3. Generate small outputs for each.
4. Analyze each output with same scorecard.
5. Compare results side by side.
6. Select winner.
7. Feed winner plus failure notes back into next pass.

## Scorecard
- **Prosody fit**: stress, syllable timing, punctuation alignment.
- **Rhythm fit**: groove, meter, density, phrase shape.
- **Melody fit**: contour, tension, release, singability.
- **Harmony fit**: cadence, functional clarity, outside-note control.
- **Form fit**: question/answer, verse/chorus, story arc.
- **Text fit**: meaning preserved, emphasis correct, hook strength.

## Selection Logic
- Highest score wins.
- If tie, prefer method with best prosody fit.
- If still tie, prefer method with simpler control and better repeatability.
- If all weak, remix top two methods and rerun.

## Agent Use
Musicom Agent should keep a method memory:
- what was tried
- what worked
- what failed
- what to try next

## Output
Save comparison result in project notes and agent research notes.
Keep the winner method as the active method for the next cycle.
