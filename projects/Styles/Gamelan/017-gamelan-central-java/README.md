# 017 - Gamelan Central Java

## Concept
Research and composition study of Central Javanese Gamelan structures, focusing on Colotomic cycles and Irama levels.

## Pattern Center
- **Key center**: D-based tonal center, similar to D Major.
- **Scale (Slendro)**: D-centered pentatonic mapping `{D, E, F#, A, B}`.
- **Scale (Pelog)**: D-centered 7-tone mapping with D as tonic.
- **Metrical Gravity**: Strong weights on beats 4, 8, 12, 16.

## Structure
- **Gongan**: 16-beat cycle.
- **Irama I**: Standard density.
- **Irama II**: Temporal expansion (1/2 Speed Balungan, 2x Speed Peking).
