## 2. Methodology & Layer Details

- **Layer Cadence:** `concrete` layer.
- **Method:** 025 Xenakis Sieve Theory.
- **Theoretical Basis:**
  - Iannis Xenakis developed Sieve Theory as a formal mathematical construction of scales, pitch spaces, and rhythmic structures via logical operations (union $\cup$, intersection $\cap$, complement $\sim$) over congruence classes (residue classes modulo integer periods).
  - A residue class $M_R = \{ n \in \mathbb{Z} : n \equiv r \pmod M \text{ for } r \in R \}$.
  - **Pitch Sieve Formula:**
    $$S_{\text{pitch}} = 3_{\{0, 2\}} \cap 4_{\{0, 1, 2\}}$$
    Evaluated over modulus period $\text{lcm}(3, 4) = 12$, this sieve selects integer residues:
    $$\{0, 2, 5, 6, 8, 9\} \pmod{12}$$
    Mapped onto tonic D (pitch class 2), this selects $\{2, 4, 7, 8, 10, 11\}$ which embeds the core diatonic and modal degrees of the Dorian universe.
  - **Rhythm Sieve Formula:**
    $$S_{\text{rhythm}} = 4_{\{0, 2, 3\}} \cap 8_{\{0, 1, 3, 4, 6\}}$$
    Evaluated over a 16-step bar ($16\text{th} = 120$ ticks), active onsets trigger at steps:
    $$\{0, 3, 4, 6, 8, 11, 12, 14\}$$
    This creates an asymmetric, syncopated driving reel rhythm with syncopations on steps 3, 6, 11, and 14, perfectly suited to a lively British/Celtic folk dance.
