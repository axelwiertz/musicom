## Concept

A D-minor chamber suite in the Baroque idiom (Prelude → Allemande → Courante →
Sarabande → Gigue → Finale), where the melodic DNA is generated by a **Xenakis
sieve** — a logical intersection of modular congruence classes — rather than by
a tonal grammar. Phase 2 then imposes the Baroque grammar: D-minor chord tones,
strict 16th-grid rhythm, and a continuo texture.

## Xenakis sieve formulas (periods over ℤ)

- **Pitch sieve** `S_p = { n : n mod 3 ∈ {0,2} } ∩ { n : n mod 4 ∈ {0,2,3} }`
  → residues mod 12 = **{0, 2, 3, 6, 8, 11}** (6-note sieve scale)
- **Rhythm sieve** `S_r = { s : s mod 4 ∈ {0,2,3} } ∩ { s : s mod 8 ∈ {0,1,3,4,6} }`
  → active 16th-steps = **{0, 3, 4, 6, 8, 11, 12, 14}** (syncopated)

## Two-phase architecture

**Phase 1 (raw draft)** — single Violin voice. The sieve walk advances an
integer index; an onset fires when the rhythm sieve is satisfied, the pitch
sieve supplies the next congruent residue, mapped to a chromatic pitch around
D4 with per-onset micro-timing jitter (±18 ticks). Result: **unquantized,
chromatic, no chord quantization, no harmony** → `-phase1.mid`.

**Phase 2 (musicom rules)** — the raw walk is chord-tone quantized per bar
(`nearest_in` over chord tones within the voice register), snapped to the 16th
grid, register-clamped, and de-duplicated. Full 5-voice texture added:
- **Lead** (Violin, ch0): sieve line, chord-quantized, 16th-grid.
- **Counter** (Violin, ch1): canon-at-the-octave, one beat delayed, in the
  contrapuntal sections (Allemande/Courante/Gigue).
- **Recorder** (Flute, ch2): sustained upper chord tones in the slow/cadential
  sections (Prelude/Sarabande/Finale).
- **Harpsichord** (ch3): continuo broken-chord arpeggiation (root-3rd-5th-3rd)
  on 8ths, every note a chord tone.
- **Cello** (ch4): quarter-note root/fifth/octave bass, every note a chord tone.

Transforms applied in raw space before quantization: transpose (+M3), diminution
(×0.5 ticks), octave_up (+12), invert (contour reflected around D4), augment
(−12 + broadened duration).

## Fixes applied

- **Chord-membership clamp bug** (found via audit, 16 violations): `quantize()`
  originally searched chord tones in `[40,100]` then clamped the result to the
  voice register *after* nearest — the clamp could land on a non-chord pitch
  (e.g. clamped to 88 = pc 4 against a Dm bar). Fixed by restricting chord-tone
  candidates to the voice register up front (`chord_tones(d, lo, hi)`) and
  removing the post-clamp. Re-exported → 0 out-of-chord.
