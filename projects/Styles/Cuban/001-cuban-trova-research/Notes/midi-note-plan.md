# MIDI Note Plan

## Global Settings
- **Tempo**: 92 BPM
- **Meter**: 4/4
- **Instrument**: Acoustic Guitar, vocal lead later
- **Register**:
  - Verse: C4-E4 center
  - Chorus: E4-A4 lift
  - Bridge: B3-D4 lower reflective zone

## Pitch Map by Section

### Verse A1
- Use stepwise motion, mostly scale tones.
- Keep phrase endings near tonic or mediant.
- Suggested contour:
  - line 1: E4 F4 G4 F4 E4 D4
  - line 2: E4 D4 E4 F4 E4
  - line 3: D4 E4 F4 G4 A4 G4
  - line 4: F4 E4 D4 C4
- Stress rule:
  - stressed syllables on beat 1 and beat 3
  - weak syllables on offbeats or tied notes

### Chorus B
- Open the range upward.
- Hook words need leap or repeated note with accent.
- Suggested contour:
  - line 5: G4 A4 C5 B4 A4 G4
  - line 6: G4 F4 E4 D4 E4
  - line 7: G4 A4 C5 B4 A4 G4
  - line 8: F4 G4 A4 G4 F4 E4 D4
- Hook target:
  - `llamas` -> A4/C5
  - `senda` -> G4/F4
  - `raíz` -> long held note, E4 or F4 depending on cadence
  - `feliz` -> final tonic landing, D4 or E4 depending on key choice

### Bridge C
- Drop register for reflection.
- Use longer note values and wider spacing.
- Suggested contour:
  - line 9: D4 C4 D4 E4 F4
  - line 10: C4 D4 E4 D4 C4
  - line 11: D4 E4 F4 G4 A4
  - line 12: G4 F4 E4 D4 C4
- Strongest question lift on line 11.
- Final line must resolve back to verse/chorus tonic center.

## Rhythmic Placement
- One lyric stress per beat where possible.
- No more than two syllables on one beat unless intentionally ornamental.
- Final syllable in each line: hold 1.5 to 2 beats if it carries the emotional close.
- Chorus repeats should keep same rhythm, maybe raise pitch by a third on the second pass.

## MIDI Implementation Notes
- Use note lengths around quarter notes for verse.
- Use more tied eighths in chorus to keep flow.
- Use longer half-note sustains on bridge question/answer points.
- Add a short pickup into each chorus line.
- Keep melodic range modest. Cuban narrative songs need clarity first.
