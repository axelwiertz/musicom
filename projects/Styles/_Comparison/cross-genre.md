# Pop/Rock Theory & Pattern Library

## Overview
Pop and Rock prioritize **hooks**, **emotional peaks**, and **vocal accessibility**. Patterns are designed for maximum memorability.

## Core Rhythms
- **Backbeat**: Heavy snare on 2 and 4.
- **The 4-Chord Loop**: I-V-vi-IV (the "Bestseller" progression).

# Electronic/Ambient Theory & Pattern Library

## Overview
Electronic music prioritizes **timbre**, **texture**, and **repetitive hypnotics**. Patterns focus on filter modulation and loop-based evolution.

## Core Rhythms
- **Four-on-the-Floor**: Kick drum on every quarter note (Techno/House).
- **Syncopated Percussion**: Off-beat hi-hats and triplets (Trap/IDM).

# Cross-Genre Synthesis: The Hybrid Logic

| Seed Genre | Target Style | Transformation | Result |
| :--- | :--- | :--- | :--- |
| **Balfolk** | **Jazz** | Add 7th/9th extensions to modal chords | Balfolk-Jazz (Modern Folk) |
| **Classical** | **Electronic** | Sequenced 16th-note counterpoint with filters | Neo-Classical / Trance |
| **Pop** | **Classical** | Orchestral arrangement of a 4-chord loop | Cinematic Pop |
| **Jazz** | **Pop** | Use ii-V-I turnaround as a bridge/peak | Sophisti-pop |
