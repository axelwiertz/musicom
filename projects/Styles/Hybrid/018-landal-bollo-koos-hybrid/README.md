# Project 018: Landal Bollo and Koos are friends

Genre: Dutch Children / Minidisco-Folk Hybrid
Key: Bb Major
BPM: 110

## Hybrid Strategy
- **Landal/Bollo (Trad Folk):** Acoustic guitar, walking bass, birds/forest sfx.
- **Roompot/Koos (Minidisco):** Driving kick, synth hooks, group clap rhythm.
- **Polo Beer (Lyrics):** Forest friends and beer walk themes.

## DNA Mapping
- Bass: Root-Fifth walking (Bb-F).
- Rhythm: Euclidean(4,16) kick + Clap on 2 & 4.
- Synth Lead: Anthemic hook based on Koos melody.
