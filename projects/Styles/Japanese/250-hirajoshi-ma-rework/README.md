# 250-hirajoshi-ma-rework

Japanese hōgaku in **D hirajoshi** (D-Eb-G-Ab-C). Rework of
`001-japanese-hirajoshi` — rebuilt through the canonical two-phase
UnitMatrixComposer workflow, doubled to 32 bars with 5 variation techniques.

- **Tempo**: 70 BPM
- **Form**: 8 sections × 4 bars (Jo / Ha / Ha2 / Kyu / Bridge / Kyu2 / Develop / Jo2)
- **Voices**: Koto (107), Shakuhachi (77), Shamisen (106), Taiko (ch9 kit)
- **Ma** (silence/space) is structural.
