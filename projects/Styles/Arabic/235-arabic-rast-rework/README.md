# 235-arabic-rast-rework

Arabic Rast maqam suite — rebuilt from `071-arabic-rast-ant-colony`
(Method 041 ACOPF), extended to 24 bars / 6 sections with 6 variation
techniques.

- Key: D Rast (12-TET approx = D Phrygian)
- Tempo: 100 BPM, 4/4
- Rhythm: Maqsum 3+3+2
- Voices: Lead (flute), Counter (violin), Harmony (strings), Bass, Pad,
  Drums (ch9)
- Two-phase: `-phase1.mid` (raw ant-colony, unquantized) + `.mid` (rules)

See `REPORT.md` for the full audit → redesign → extension narrative and
verification numbers.
