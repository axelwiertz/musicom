# Project 023: Flamenco 16-Bar Study

## Concept
16-bar study in E Phrygian using the Andalusian Cadence. Focus on 3/4 Fandango-style weight and dominant-V resolution.

## DNA
- **Mode:** E Phrygian (mapped as Am-G-F-E for cadence)
- **Meter:** 3/4
- **Tempo:** 120 BPM
- **Cadence:** `i - VII - VI - V` (Repeating 4-bar cycle)

## Rhythm DNA
- `█░░ █░░ █░░` (Strong downbeat emphasis)
