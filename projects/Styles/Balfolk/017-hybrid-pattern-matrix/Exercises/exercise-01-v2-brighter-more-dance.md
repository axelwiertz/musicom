# Exercise 01 v2 — Brighter + More Dance

User feedback on v1:

```text
1. Most danceable: A Balfolk
2. Strongest harmonic pull: B Jazz
3. Hybrid identity: balanced
4. Next transformation: brighter + more dance
```

## Design goal

Keep hybrid balanced, but push two rows:

```text
Dance row: stronger jig gravity
Harmony/melody color row: brighter #11 bulb
```

## MusicMatrix rows

```text
Row 1: Dance Pulse / Strong Jig
Row 2: Shaker Eighth Grid
Row 3: Bass Octave Push
Row 4: Bright Jazz Color Harmony
Row 5: Folk Lead with Lydian Bulb
Columns: 8 bars of 6/8
```

## What changed

### More dance

- Tempo raised from 142.5 quarter BPM to 148 quarter BPM.
- Stronger accents on count 1 and 4.
- Added shaker eighth grid.
- Added bass octave punches on 1 and 4.

Rhythm DNA:

```text
Kick:   █░░█░░
Shaker: ██████
Bass:   █░░█░░
Count:  1 2 3 4 5 6
```

Meaning:

- Kick and bass align on jig gravity.
- Shaker fills the air without changing the dance structure.

### Brighter

Added C# as a bright #11 color over G13#11 in bars 4 and 7.

```text
G13#11 = G B F E C#
Bright bulb = C#
Resolution = C# -> D
```

This is a controlled Lydian brightness. It does not replace the Dorian folk base. It appears briefly and resolves.
