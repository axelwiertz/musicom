# 305-minimalism-phase-variations

Minimalism redesign of `001-minimalism-phase-study` (Steve Reich
"Clapping Music"-style phase piece, E(5,12) Euclidean marimba cell).
Redesign: 24 → **32 bars**, 8 → **10 sections**, **7 variation techniques**.

- Key: C major (source C-pentatonic DNA re-expressed as chord-tone arpeggios)
- 120 BPM · 4/4 · 480 TPB · BAR 1920
- Form: Intro(2) Phase1(4) Phase2(4) Phase3(4) Phase4(4) Phase5(4)
  Bridge(4) Phase6(2) Resolve(2) Coda(2)
- Voices: MarimbaA(12) · MarimbaB(12) · Pad=Strings(48) · Bass(32) · Drums(ch9)
- Variation: phase-walk, retrograde, inversion, augmentation, register shift,
  density/diminution, relative-minor re-orientation.
