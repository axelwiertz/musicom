# 001-country-loop-seamless

**Style:** Country
**Mood:** Upbeat, danceable, nostalgic
**Key:** G Major
**Tempo:** 120 BPM
**Bars:** 16
**Loop:** Seamless (end → start)

## Concept
- Classic Country I-IV-V progression in G.
- Fiddle lead with syncopated rhythm.
- Drums: Bass + Snare + Light Brush.
- Bass: Walking line.
- Ending chord resolves to start chord (G).

## Structure
- 4-bar phrases × 4 = 16 bars.
- Phrase 1: G → C
- Phrase 2: G → D
- Phrase 3: C → G
- Phrase 4: D → G (resolves to start)

## Files
- MIDI: loop.mid
- Audio: loop.wav (uncompressed)
- Scores: loop.xml
- src: regen.py
- Dashboard: index.html
