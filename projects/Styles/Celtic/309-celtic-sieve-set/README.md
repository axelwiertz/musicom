# 309-celtic-sieve-set

Celtic reel-set composed via **Xenakis Sieve Theory** (method 025, Rules-Based,
concrete layer). Nightly composition job 2026-11-17.

## Concept

Six through-composed phrases (S1–S6, 4 bars each = 24 bars) where each phrase is
generated by a distinct **modular sieve** over pitch and rhythm. A Xenakis sieve
is a congruence rule `x ≡ r (mod m)`; intersecting/unioning sieves over the
chromatic pitch space builds a pitch pool, and over the 16th-grid builds an
onset pattern. Phase 1 emits the raw sieve walk (single violin, off-grid,
chromatic); Phase 2 disciplines it to D Mixolydian + chord tones and arranges a
5-voice Celtic texture.
