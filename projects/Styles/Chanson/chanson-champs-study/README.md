# Chanson Française — "chanson-champs-study"

Composition study of 1960s Chanson Française / Variété ("Les Champs-Élysées"
style): march-like 4/4, musette accordion, strummed guitar, light brass, swinging
strings, sing-along chorus.

- **Style**: Chanson Française (added to `STYLE_REGISTRY` as `"chanson"`).
- **Key / tempo / form**: C major · 126 BPM · Intro-Verse-Chorus-Verse-Chorus-Outro (40 bars).
- **Harmony**: I–V–vi–IV (verse), resolving chorus.
