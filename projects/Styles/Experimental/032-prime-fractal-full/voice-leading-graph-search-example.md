# Example Composition: Voice-Leading Graph Search / Neo-Riemannian Pathing

## Goal
Smooth harmonic motion with minimal voice movement.

## Harmony Path
- I -> vi -> IV -> ii -> V -> I

## Voice-leading sketch
- Soprano: E -> E -> F -> E
- Alto: C -> C -> A -> C
- Tenor: G -> F -> A -> G
- Bass: C -> A -> D -> C

## Section plan
- A: establish tonic and common tones
- B: pivot through relative minor and subdominant color
- C: intensify via predominant to dominant
- D: return to tonic with closure

## Method notes
- Preserve common tones.
- Move remaining voices by smallest legal interval.
- Treat each chord as a graph node.
- Treat each transition as a minimal-motion edge.
