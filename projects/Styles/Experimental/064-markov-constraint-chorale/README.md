## Concept

A four-voice chorale in **G minor (aeolian)** whose soprano is generated by an
order-1 **Markov-Constraint Wavefront**: each next pitch is drawn from the
transition neighborhood of the current pitch (stepwise bias, `|interval| <= 7`
semitones) while every candidate is simultaneously validated against global
scale-membership and a per-section glide band (the "wavefront"). The result is
a locally singable contour that is also globally bounded — the defining
tension of MCWS.

- **Key:** G minor (aeolian) — `G A Bb C D Eb F`
- **Tempo:** 84 BPM, 4/4
- **Form:** 4 sections x 2 bars = 8 bars total
- **Voices:** Soprano (Flute), Alto (Strings), Tenor (Strings), Bass (Bass)

## Harmonic Progression (rules-validated)

```
i  -> VII -> III -> VI   (Gm - F - Bb - Eb)
```

Validated against `rules/progression.py`:

| Pair | Function class | Verdict |
|------|---------------|---------|
| 1 -> 7 | tonic -> any | legal (tonic -> any) |
| 7 -> 3 | dominant -> tonic-prolongation | legal (interrupted/deceptive cadence) |
| 3 -> 6 | tonic-prolongation -> tonic-prolongation | legal (prolongation, free) |

The final `VI -> i` return implied by the cycle cadences plagally back to
tonic. Chord triads are computed through the canonical
`Scale7ChordDegree.get_diatonic_note()` helper — no off-by-octave scale
inversions on wrap degrees.

## Two-Phase Architecture

**Phase 1 (generative draft):** Markov-constrained pitch walk over the
G-aeolian pool; 16th-note stochastic density ramp `0.55 -> 0.85` across the
four sections (rhythmic build). Raw pitch DNA (first 12 per section):

```
i (Gm):   [74, 75, 72, 77, 75, 77, 75, 69, 74, 74, 74, 77]
VII (F):  [69, 75, 70, 72, 70, 69, 69, 67, 69, 72, 75, 77]
III (Bb): [75, 72, 74, 69, 72, 72, 70, 72, 75, 69, 70, 67]
VI (Eb):  [70, 69, 70, 70, 75, 74, 74, 70, 72, 69, 70, 70]
```

**Phase 2 (musicom rules):**
- Soprano quantized to nearest chord tone (consonant melody).
- Alto/Tenor/Bass = diatonic block harmony from the section triad.
- `VoiceLeadingRules.optimize_voice_leading()` minimizes voice-leading distance.
- Phase 2c correction pass: inversion rotations searched for zero
  parallel/hidden-fifth violations — **final: 0 violations**.
- Zero-drift gate: `UnitMatrixComposer.validate()` **PASS** (3137-byte MIDI).
