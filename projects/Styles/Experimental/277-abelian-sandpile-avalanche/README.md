## Concept

The piece is generated by the **Bak–Tang–Wiesenfeld abelian sandpile** on a
14×192 lattice (14 pitch rows = two octaves of D minor; 192 time columns = one
eighth-note each). A "composer's hand" advances the drop site down the columns
and arches it across the register (per-section grain density 4/6/8/10/8/4), so
the avalanche activity builds from a sparse intro to a dense peak and decays to
a sparse coda. Each cell toppling is a note — the avalanche cascade *is* the
rhythm (power-law bursts), and the 2D diffusion spreads it across adjacent
scale degrees (stepwise runs) and adjacent time slots.

- **Phase 1** (`-phase1.mid`): raw toppling stream — float pitch + chromatic
  jitter, off-grid onsets, single voice, no harmony.
- **Phase 2** (`-perfect.mid` + `-humanized.mid`): tiered pitch discipline
  (strong = scale+chord, weak = scale), 16th grid snap, dedup, voice-leading,
  tagged chromatic approach ornaments on the lead, 5-voice arrangement.
