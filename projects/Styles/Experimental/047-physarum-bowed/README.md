# Project 047: Physarum Network Optimization & Bowed String physical Modeling Synthesis Study

Algorithmic music study leveraging biological network models and acoustic physical modeling.

## Methods
- **Composition**: Method 035: Physarum Polycephalum Transport Network Optimization (PPTNO)
- **Sound Production**: Method SP-024: Bowed String Physical Modeling (Friction-Induced Waveguide Synthesis)

## Concepts
- **PPTNO**: Uses a slime mold network solver in 2D coordinate space. Active food sources shift according to the harmonic plan (Eb Major &rarr; F Major &rarr; G Minor &rarr; Bb Major). Melodic triggers are generated via peristaltic contractive waves of the active tube walls, demonstrating 4 distinct structural phases (Exploration, Optimization, Minimal Spanning Tree, and Decay/Resolution).
- **SP-024**: Direct physical synthesis of a violin-like string voice using bidirectional waveguide delays representing the neck and bridge segments. Solves stick-slip exponential sliding friction dynamically via a 4-step Newton-Raphson numerical solver at 44.1 kHz.

## Structure
- **BPM**: 110
- **Scale**: Bb Major / G Minor
- **Form**: 8 Bars of 1920 ticks each (zero track-drift aligned via `UnitMatrixComposer`).
- **Voices**: Lead (Bowed physical model), Pad (Synth string pad), Bass (Bass movement).
