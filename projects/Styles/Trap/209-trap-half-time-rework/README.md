# 209-trap-half-time-rework

Rework of `001-trap-half-time` (Trap). Longer (24 bars / 6 sections) + more
varied. Two-phase architecture: Brownian-walk raw draft → musicom rules
(chord-tone quantization, grid snap, dedup, register + voice-leading).

- Key: C natural minor
- Tempo: 140 BPM (half-time feel)
- Voices: KickSnare (ch9), Hat (ch9), 808 (bass), Pad, Lead (square), Counter
