# 095 — Klezmer Tintinnabuli Freylekhs

**Style:** Klezmer (freylekhs wedding-dance, 124 BPM, D harmonic minor)
**Method:** 079 Tintinnabuli Composition (TINC) + ABS-003 Z-variation bridge color
**Status:** complete — MIDI phase1 + phase2, Audio WAV + OGG, Analysis audits

## Concept
Freylekhs dance built from Arvo Part's tintinnabuli pair: a conjunct violin
M-voice in D harmonic minor shadowed the whole piece by a clarinet T-voice on
the fixed D-minor triad (D-F-A), over trumpet calls, dulcimer chops, oom-pah
bass and freylekhs drum kit. Bridge borrows an ABS-003 Z-pair hexachord color
(matched tension, fresh notes).
