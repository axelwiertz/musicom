## Concept

The piece is generated by a population of **16 coupled phase oscillators** (the
Kuramoto model, integrated via the mean-field `r·e^{iψ}` trick). Each oscillator
maps to a diatonic pitch row of A natural minor; each phase wrapping of `2π`
fires a note, with velocity set by the local **order parameter `r`** (the degree
of synchronization). A "composer's hand" arcs the coupling `K`:

- **Intro** `K=0.7` — desynchronized texture (r ≈ 0.36, near the finite-size noise floor)
- **Break** `K=0.7→2.8` — partial entrainment, emergent polyrhythmic lock-in (r ≈ 0.48)
- **Drop** `K=3.5` — full phase-lock (r ≈ 0.94), the ensemble collapses onto a unified driving pulse
- **Outro** `K=3.5→0.7` — decay (r ≈ 0.77)

- **Phase 1** (`-phase1.mid`): raw firing stream — float pitch + chromatic
  jitter, off-grid onsets, single voice, no harmony.
- **Phase 2** (`-perfect.mid` + `-humanized.mid`): tiered pitch discipline
  (strong = scale+chord, weak = scale), 16th grid snap, dedup, voice-leading,
  tagged chromatic approach ornaments on the lead, 5-voice techno arrangement.
