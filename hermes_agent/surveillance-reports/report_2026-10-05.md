## Items (one per gear finding)

- **Loopop Convolution Playground** (synthtopia.com, 2026-10-01)
  Tech: Browser-based application for designing impulse responses via 10 DSP techniques: reverse-bloom (reversed exponential decay→attack transient), drawn echoes (user-specified multi-tap sparse impulse trains), chord bodies (additive sine partial sums), filter sweeps (frequency chirps), vowel formants (formant-shaped noise bursts), spectral delays (FFT-based frequency-dependent delay), rain (dense stochastic impulse trains), reverb (noise-with-exponential-decay), metallic bloom (inharmonic stretched-harmonic partial sums), and FM body (carrier-modulation sidebands as IR). Free browser version; export behind Patreon.
  Replicable: YES
  Musicom path: sound/effects/ir_designer.py (SP-099)

- **Kaona B.A.C.H. Composition Systems** (synthtopia.com, 2026-09-28)
  Tech: Four-voice Eurorack/MIDI composition generator module offering 12 algorithmic languages. FRACTAL previously replicated (SP-098). Remaining 11: FUGUE (subject-answer-countersubject-episode exposition), CANON (imitation via transposition/contrary/retrograde/augmentation), PROBA (Markov chains with multiple transition vocabularies), TINTINNABULI (triad-based voice leading, Pärt-style), MINIMAL (phase-shifting/addition/substitution/hocketing processes), CELLULAR (Wolfram 254-rule cellular automata → musical material), TREE (L-system branching → melodic paths), MOTIF (32-cell melodic/rhythmic collections in 5 styles), HYBRID (multi-engine distribution across 4 voices), GROOVE (4 rhythmic roles from 64-structure library), GROOVE_MIX (pitches from melodic language + rhythmic structures). Onboard SD preset storage, CV pitch/gate/mod outputs, MIDI.
  Replicable: YES
  Musicom path: sound/generators/bach_composer.py (SP-100)

- **Sophie for Digitakt — Metallic Percussion** (synthtopia.com, 2026-09-30)
  Tech: Unofficial firmware mod (open-source build-it-yourself from OS 1.53) adding 4 metallic percussion synthesis models: FUSE, BOOM, PIPE, SHARD. Derived from fixed-point adaptation of Sophie for Schwung. Uses Digitakt's existing AMP/filter/mixer/effects signal path. Four distinct metallic timbres produced by different parameter configurations.
  Replicable: PARTIAL — specific parameter spaces for 4 models are proprietary; metallic percussion physical modeling conceptually covered by sound/synthesis/modal.py + karplus_strong.py

- **Nibbi / Chompi Open-Source Sampling Keyboard** (synthtopia.com, 2026-10-02)
  Tech: Chase Bliss Chompi sampling keyboard firmware released as open source; TemeculaDSP ported it to VST3/AU/AAX as free Nibbi plugin. Record and sample sounds across keyboard, layer tape-style loops, apply lo-fi saturation, wow/flutter, delay, reverb, and filters. Tactile immediate sampling workflow.
  Replicable: PARTIAL — VST wrapper of open-source firmware; sampling engine conceptually covered by sound/generators/sample_slicer.py; tape effects by sound/effects/tape_delay.py

- **Cassettone / SISKworks Modified Tape Player** (synthtopia.com, 2026-09-28)
  Tech: Modified cassette playback instrument ("poor man's Mellotron"). Five button-triggered tape voices with motor-speed tuning per key. Daisy microcontroller adds delay/reverb/filter/harmonizer/reverse grain effects. Step sequencer with normal/reverse/bounce/random directions, per-step on/off, tempo/length/glide/swing controls, hold mode for drones. CV/gate/clock I/O, planned 1V/oct tuning.
  Replicable: PARTIAL — step sequencer with direction modes conceptually overlaps sound/generators/trig_cond_seq.py + ratchet_seq.py; tape playback engine not replicable in pure DSP

- **Spitfire Audio Phoenix** (musictech.com, 2026-09)
  Tech: Hybrid synth collaboration with BT. 6 engines: spectral wavetables, FM (6 operators, 34 algorithms, 48-osc unison), sampler, 2OP FM transients, sub generation, noise oscillator. Cross-modulation between all engines. Dual stereo synthesis chains per voice. 8 multi-segment MetaSequencers, 636 rhythm patterns, probability arpeggiator (StutterEdit rhythmic language). 37 effects (spectral smearing→granular reverb→vinyl emulation). 16-voice MPE. 50 orchestral instruments from Spitfire + BT's private archive.
  Replicable: PARTIAL — individual engine types in sound/ (wavetable, FM, sampler, noise); integrated 34 FM algorithms + spectral warping + probability arpeggiator are proprietary

- **Melatonin Sine Machine** (soundonsound.com, October 2026)
  Tech: Pure additive synthesizer with up to 511 sine oscillators per voice, 20-voice polyphony (10,000+ simultaneous oscillators). Per-harmonic envelope control with harmonic skew curves, per-oscillator LFOs, 5 main programming pages (Volumes, Envelopes, LFO, Morph, Mod Matrix). Each partial has independent envelope and LFO. Efficient CPU usage.
  Replicable: PARTIAL — additive synthesis core exists in sound/synthesis/additive.py; the per-partial envelope/LFO UI and engine optimizations are proprietary. SoundWave additive module provides partial ADSR control.

- **Verbos Haas Zone Processor** (synthtopia.com, 2026-09-29)
  Tech: Eurorack module with 3-tap modulated delay bank (Tap1: <1–20ms, Tap2 chained +1–20ms, Tap3: 9–42ms) inspired by Marshall Time Modulator. VCO LFO (triangle/square/sawtooth, 1-min-cycle to audio rate), envelope follower, 2-pole HP+2-pole LP cascaded bandpass filter, VC blender for dry+3-tap mix, feedback through BPF. Chorus/flange/phase cancellation/doubling/ADT/waveshaping.
  Replicable: YES (already done — 2026-10-01 scan)
  Musicom path: sound/effects/haas_zone.py (SP-096, DONE)

- **Finalist 2** (soundonsound.com, 2026-09-25)
  Tech: Algorithmic mixing tool (no AI). Hand-rolled algorithms extract hundreds of data points from audio, mapped to mixer via genre-based presets. Multi-band dynamics, transient shaping, clipper-limiters, limiter network, analog warmth emulation, mid-side processing. Up to 64 stems, automatic stem placement, stem bounce (drums/bass/back/front), versions/templates, offline rendering.
  Replicable: PARTIAL — multiband dynamics in sound/effects/mastering.py; transient shaping conceptually covered; specific signal-analysis + genre preset engine is proprietary

- **Sampleson Backgrounds** (synthtopia.com, 2026-09-29)
  Tech: Keyword-to-soundscape tool using semantic audio retrieval. Maps words to 22,000 audio cells + 11,000 local embeddings via cosine-similarity matching. Drag keywords onto canvas to combine concepts (strings+rain+bass+thunder). Local processing, standalone+VST3/AU.
  Replicable: PARTIAL — requires proprietary 22K sample library + embedding vectors; retrieval algorithm is standard cosine similarity
