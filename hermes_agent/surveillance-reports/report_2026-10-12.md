## Items (one per gear finding)

### Replicated (YES) this scan

- **Analogue Solutions Filtopia — 5-Filter Parallel Monosynth** (soundonsound.com, 2026-10-09)
  Tech: Hardware monosynth with 5 Oberheim SEM-inspired analogue filters wired in parallel. Each 12dB/oct (2-pole), with independent cutoff offset. Filters 1&5 switchable LP/BP; filters 2/3/4 fixed BP. 3 VCOs routable to any filter, 2 sub-oscillators, noise gen, 2 VCAs, 3 ADSRs, 2 LFOs, 8-step sequencer. The parallel multi-filter concept creates multiband sweeps and vowel-like formant clusters.
  Replicable: YES
  Musicom path: sound/effects/parallel_filter_bank.py (SP-103)

- **Sound Particles Brightness Panner 2** (soundonsound.com, 2026-10-08)
  Tech: Dynamic auto-panner where pan position is controlled by spectral brightness/centroid analysis. v2 adds independent paths per channel, built-in mixer, Virtual Centre, custom speaker layouts, Ambisonics support. Brightness Panner uses spectral centroid tracking — brighter content moves differently from darker content.
  Replicable: YES (Brightness Panner core)
  Musicom path: sound/effects/spectral_panner.py (SP-105)

- **Cherry Audio Pentaphonic — Parameter Animator** (synthtopia.com / soundonsound.com, 2026-10-07)
  Tech: The Pentaphonic's Parameter Animator is a 16-step modulation pattern generator that provides sequenced modulation for synthesis parameters: filter cutoff, resonance, oscillator pitch modulation, and oscillator gain. Each step stores a target value with interpolation between steps. Differs from step sequencers by producing continuous floating-point CV signals for parameter modulation.
  Replicable: YES (Parameter Animator module)
  Musicom path: sound/generators/param_animator.py (SP-104)

### Partial (not replicated) this scan

- **Imaginando Colapso — Atomic Synthesizer** (musictech.com, 2026-10-10)
  Tech: Soft synth using 22 periodic-table element emission spectra as oscillator timbres. Three-stage processing chain: additive→granular→subtractive. 8 voices × 3 oscillators, 4 LFOs, 4 envelopes. Based on Heisenberg Uncertainty Principle: "To hear pitch, we need time."
  Verdict: PARTIAL — Emission-spectrum wavetables conceptually covered by spectral_wavetable.py; three-stage processing chain = existing modules; full VST not replicable.

- **AnalogFX LARYNX — Formant Triple-Filter Synth** (musictech.com, 2026-10-07)
  Tech: 37-key CEM3340 analog synth with triple-filter formant architecture (PEAK 1 + PEAK 2 + LPF), 16 pre-programmed voice formants, chord mode, stereo delay, 16-step sequencer, arpeggiator. 50-unit limited run.
  Verdict: PARTIAL — Hardware synth. Formant filters covered by vowel_filter.py + formant_voice.py.

- **Idle Foundry CA-72 — Free Minimoog Emulation** (musictech.com, 2026-10-07)
  Tech: Open-source VST3/CLAP Minimoog emulation via SPICE/ngspice circuit simulation of original CA3046 oscillator board. 3 oscillators, Moog ladder filter, 2–10 voice poly mode.
  Verdict: PARTIAL — Circuit-level SPICE→ngspice modelling ≠ pure DSP. Subtractive architecture covered by mono_synth.py.

- **UDO DMNO ON — 8-Voice Hybrid Desktop Synth** (synthtopia.com, 2026-10-07)
  Tech: FPGA digital oscillators + analog VCF, 2-part multitimbral, Dynamic Multi-Core Stereo VCF, 8 Play Modes (Single/Dual/Split/Random/Chaos/Cascade), binaural mode, expandable. $2,850.
  Verdict: PARTIAL — Hardware. Binaural mode + play modes already in binaural.py.

- **Olydian VC-01 Voicecrafter — Vocal Synthesizer** (synthtopia.com, 2026-10-11)
  Tech: Hardware vocal synth: 380 syllables, formant synthesis + consonant-vowel sampling, 6-voice poly, 20+ sample banks, 3-octave keyboard.
  Verdict: PARTIAL — Hardware. Formant synthesis covered by formant_voice.py.

- **Bubblegum — Free Polyphonic Pitch Editor** (synthtopia.com, 2026-10-08)

  Verdict: PARTIAL — Phase-vocoder/spectral pitch shifting in phase_vocoder.py. Buggy alpha not replicable.

- **Schwabe Digital HiFAL 2** (soundonsound.com, 2026-09-15)

- **WeissKlang KlangFormer 2** (soundonsound.com, 2026-10-11)
