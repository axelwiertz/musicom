## Items (one per gear finding)

- **Modartt Airteq** (soundonsound.com, 2026-09-16)
  Tech: Physical-modelled pipe sound-design instrument built on Pianoteq-lineage modelling plus their "Dynamic Aerophone Modelling (DAM)": up to five virtual flue pipes per patch, each with independent air-supply (wind pressure/flow) controls, one global instrument-wide air envelope, 2 envelopes + 3 LFOs, MPE/aftertouch expression. Airflow is the continuous performance parameter — driving breathiness, overblow and timbre in real time.
  Replicable: YES
  Musicom path: **DONE** — sound/synthesis/air_pipe.py (SP-084). `AirPipe`: physical length from pitch with end correction (L′ = L + 0.61r), open (1:2:3…) vs stopped (1:3:5) mode bank, saturating jet drive `tanh(pressure·drive)` + pressure-scaled turbulence noise, Ising-style overblow threshold (energy migrates to mode 2 above 0.75), `air_mod` callable = per-sample air modulation (the DAM hook). `AirPipePatch`: 5-pipe rack, per-pipe air_depth/balance/detune, global air envelope, MPE pressure array. Presets/UI not replicated.

- **GlitchShredder** (synthtopia.com, 2026-09-16)
  Tech: iOS AUv3/standalone effect that captures incoming audio fragments and repeats/reverses/recombines them in real time. Chopper engine: 16 segment slots per channel, independent L/R processing, Glitch Probability + Reverse Probability rolls, quantized jumps, transient detection for segment capture, Stutter Sync following host tempo / manual BPM / tap tempo.
  Replicable: YES
  Musicom path: **DONE** — sound/effects/glitch_chopper.py (SP-085). `GlitchChopper` + `ChannelChopper`: spectral-flux transient detection, 16-slot segment banks snapped forward to transients within their grid cell, per-pass glitch/reverse probability RNG (deterministic per seed), quantized jump grid (q steps/bar) with slot-advance readout, bar-length stutter sync from bpm, fully independent L/R RNG streams + banks. AUv3/iOS hosting not replicated.

- **HarmonyKeen** (synthtopia.com, 2026-09-15)
  Tech: Rule-based (not neural) harmony assistant: reads a whole monophonic MIDI melody, finds phrases and cadences, picks a chord sequence that fits, then writes harmony voices using music-theory voice-leading; styles from a single added line through close vocal harmony to four-part writing; deterministic per settings; output is editable MIDI.
  Replicable: YES
  Musicom path: **DONE** — sound/generators/harmony_writer.py (SP-086). `HarmonyWriter`: phrase segmentation (rest gaps + max length), per-note diatonic-triad fit scoring (root 3 / third 2 / fifth 1, cadence bias V→I at phrase ends), SATB voicing with range clamps + "law of the shortest way" voice-leading vs previous pitch, soprano = melody folded into range, style 1–5 (1 line → close harmony → SATB → SATB + bass doubling), deterministic across seeds. VST3/AU hosting + app UI not replicated.
