### 1. Steinberg Cubase 16 — Spectral AudioWarp
(Synthtopia 2026-11-04 · MusicTech 2026-11-04)

**Tech:** New time-stretch and pitch-shift algorithms developed by Steinberg's HALion team, explicitly aimed at *extreme* transformations and sound-design use rather than transparent dialogue stretching. The rest of the release is workflow: Instrument Stacks (multiple VST/sampler/drum tracks played as one instrument with per-layer filtering), six-stem separation, Key Editor Strum + Stretch Selection, Omnivocal Basic vocal synthesis, MIDI 2.0 Note Expression and orchestral articulation messages, custom CC names, Ableton Link, 16 audio sends and an extended ASIO-Guard buffer.

**Replicable:** YES (the two algorithmic warps). Six-stem separation is PARTIAL — see item 7.

**Musicom path:** DONE — `sound/effects/spectral_warper.py` (**SP-142**)

### 2. Cubase 16 — Key Editor Strum + Stretch Selection
(Synthtopia 2026-11-04)

**Tech:** Strum offsets the onsets of a chord's notes to give programmed chords a strummed performance character. Stretch Selection expands or compresses a MIDI passage to a new duration, including shapes that produce accelerando and ritardando — i.e. the onsets are remapped through a time-warp curve rather than uniformly scaled.

**Replicable:** YES (pure absolute-tick event arithmetic).

**Musicom path:** DONE — `sound/generators/strum_stretch.py` (**SP-145**)

### 3. Klevgrand Altitude Harmony
(Sound On Sound news 2026-10-28)

**Tech:** Simplified take on the Altitude pitch-correction/harmony engine, built with Focusrite. A single Style control moves from transparent corrective tuning to hard-tuned vocoder-style snap; the processing "leaves formants unaffected so voices retain their original character even when pushed hard". A Harmonies parameter generates up to three additional parts above or below the lead, from a user scale strip or custom notes. Four one-knob characters: Clones, Droid, Vibrato, Tremolo. Low-latency vocal-register modes for tracking and stage.

**Replicable:** YES (classic PSOLA + YIN family; the commercial tuning heuristics and GUI are not replicated).

**Musicom path:** DONE — `sound/effects/formant_harmonizer.py` (**SP-143**)

### 4. Behringer 1601 Sequencer (ARP 1601 clone)
(Synthtopia 2026-11-04)

**Tech:** Eurorack copy of the 1970s ARP 1601: 16 steps splittable into two independent 8-step patterns; three gate buses; free 10-octave CV pitch range; Skip and Reset buttons with CV inputs, and per-step switches selectable as Skip *or* Reset; clock pulse-width control plus CV input that sets gate length from staccato to legato; clocked Gate 1 output for accents built from the Gate Bus 1 switches; CV input for transposing the sequence; position-1 CV output for triggering events on loop restart; separate quantiser inputs for external CV; MIDI/USB with MIDI channel and transport. $279.

**Replicable:** YES (sequencing behaviour; panel, 42 controls and hardware I/O are not).

**Musicom path:** DONE — `sound/generators/arp1601_seq.py` (**SP-144**)

### 5. XLN Audio RC-20 Retro Color V2 — Echo + Loss/Codec
(MusicTech weekly plugin round-up 2026-11-04)

**Tech:** The Echo module is an internal delay in which the other modules (Wobble, Distort, Space, …) are applied to the *feedback loop*, so each repeat is progressively wobbled/distorted/band-limited; Echo also works as a granular delay with reverse and pitch controls. Loss gains a Codec mode — "MP3-style compression and digital degradation". Space adds 32 reverb types, Distort adds three types plus an Overload parameter; moveable modules, varispeed-style pitching, tempo sync, 250+ presets, loudness matching.

**Replicable:** YES for the feedback-loop architecture and the codec degradation model (reverb *types* and presets are content).

**Musicom path:** DONE — `sound/effects/feedback_loop_fx.py` (**SP-146**)

### What the DSP actually does (short form)

- **SP-142** — 75 %-overlap STFT; per-bin instantaneous frequency from the phase difference; synthesis phase accumulated and then **phase-locked per spectral-peak region** (all bins in a peak's region take the peak's phase + their own analysis offset). Transients are detected by spectral flux against an absolute floor and get a **phase reset** instead of accumulation, so attacks stay sharp. Pitch shift is `shift_bins(mag, r)` followed by a **cepstral-envelope correction**: the moved envelope is divided out and the original (or deliberately formant-shifted) envelope put back, then frame energy is matched.
- **SP-143** — YIN/CMND f0 tracking per 1024-sample frame; **PSOLA** grains of two local periods are re-laid at `period/ratio` spacing, so grains are reused rather than resampled and the spectral envelope does not travel with the pitch. Correction target = scale-snap with median smoothing, then a one-pole retune (style → 120 ms … 0 ms). Harmony = diatonic degree arithmetic (so a "third" is major or minor as the key requires) → per-frame ratio → separate PSOLA pass per part.
- **SP-144** — clock/step state machine: Skip and Reset are *switch positions* (`mode`) evaluated when the head lands on the step, Reset jumping to the block start without emitting; three gate buses with bus-1 accent velocity; gate length = `pulse_width + pw_cv` × step ticks; transpose applied before scale quantisation (hardware order); position-1 flag emitted on block entry.
- **SP-145** — chord grouping by onset tolerance, order by pitch, onset offset = `curve(u) × spread`, optional velocity ramp/jitter; stretch maps normalised onset `u → w(u)` (accel = `1-(1-u)^γ`, rit = `u^γ`) scaled to the new span, with note ends mapped through the same warp so lengths follow the local derivative.
- **SP-146** — sample-accurate feedback loop: fractional read position modulated by wow + flutter + bounded random drift (in cents → samples), then per repeat tanh drive with gain compensation, tone lowpass, optional codec stage (band-limit + bit quantisation from the bitrate), then an all-pass diffuser before the buffer write. `spectral_codec` is the offline version: band-limit to a bitrate-dependent cutoff and quantise log-magnitudes on a bitrate-dependent step, resynthesise with original phase.
