## PARTIAL Notes

- **Overtonium**: Additive synthesis core already exists in sound/synthesis/additive.py. Overtonium's 32-channel per-partial DAW-style UI, 6 keyboard temperaments, global FX rack (wobble/tape echo/reverb), MPE support, and 28 presets are UI+content, not new DSP primitives. Per-partial drift/mono modulation could extend additive.py incrementally but would duplicate without the GUI.
- **Scaler EQ Pro**: Key-aware Harmonic Peak filters require a specific patented algorithm for scale-snapping EQ bands. While sound/effects/filter.py provides biquad/SVF filter primitives, the musical key/scale-aware filter routing + MIDI-playable bands are a DAW-integration concept, not a standalone DSP method.
- **Wave Emulation**: The Waldorf Wave emulator is an ongoing open-source reverse-engineering project (68000 CPU emulation, ASIC behavioral model, firmware execution). Our spectral_wavetable.py covers the wavetable synthesis concept but not the cycle-accurate hardware model.
- **Finalist 2**: The algorithmic mixing engine uses trained signal analysis + genre presets + proprietary hand-crafted mapping. Our mastering.py provides the component dynamics/warmth units but not the trained analysis pipeline.
- **4MS LEQA**: Hardware Eurorack module with circuit-specific CV behavior and component-level emulation. EQ/comp component concepts exist in filter.py/mastering.py but without the specific circuit models.
- **Knobula Drum Farm/ Woovebox/ Nagi/ Lunacy NOVA**: These products bundle existing DSP concepts (covered by our modules) into integrated hardware or software platforms with proprietary UIs, sample libraries, or hosting infrastructure.
