## Items (one per gear finding)

### Implemented this scan (Replicable = YES)

- **FAC Shifter — multiband stereo frequency shifter, AUv3/iOS/macOS** (synthtopia.com, 2026-11-18)
  Tech: Three-band frequency shifter that SSB-modulates the analytic (Hilbert) signal, giving *linear-in-Hz* spectral translation rather than pitch shift. Crossover is 3-band with selectable slopes from 6 dB/oct to 192 dB/oct, plus feedback and "internal quadrature fuzzing" that deliberately corrupts the 90° relationship. Independent L/R sideband choice (positive/negative/both) and MIDI Anchor/Follow modes keep shifts musical by anchoring the shift to a played note.
  Replicable: YES
  Musicom path: DONE — `sound/effects/multiband_freq_shifter.py` (**SP-161**)

- **Pikoto — four-operator FM groovebox** (synthtopia.com, 2026-11-18)
  Tech: 4-op FM engine with a compact algorithm set (Digitone/OP-Z/Volca FM lineage) inside a four-track step sequencer that carries per-step parameter locks. The groovebox behaviour — not the FM core — is the differentiator: ratchets, step conditions and locks let one pattern supply bass, chords and percussion.
  Replicable: YES
  Musicom path: DONE — `sound/generators/fm_groovebox.py` (**SP-162**)

- **DJW Audio DW-303 — open-source TB-303-style bass synth** (synthtopia.com, 2026-11-13)
  Tech: Stage-by-stage circuit model of the 303 (oscillator, 4-pole ladder, envelopes, VCA) built from the schematic, with Full "complete circuit simulation" vs Economy quality modes and accent circuitry that interacts with resonance. Sequencer reproduces the pitch-mode/time-mode programming, accents, slides, ties and rests.
  Replicable: YES — **topology level only** (vendor's hardware-fitted coefficient sets remain unpublished and are *not* faked)
  Musicom path: DONE — `sound/synthesis/tb303_circuit.py` (**SP-163**)

- **AARM ADEPT — multi-playhead MIDI/CV sequencer** (synthtopia.com, 2026-11-17)
  Tech: 12 tracks × **three configurable playheads per track**, each head with independent length, direction, clock division, clock source and output, so one pattern yields several concurrent interpretations (forward bass + reversed/differently-clocked copy). 11 sequencer types (Note Grid, Drum Grid, MODU, Deflector, Euclid, Trapdoor, Pathways, Cube, Orbit, Logic, Pachinko); types are switchable without data loss; generative types can trigger whole tracks.
  Replicable: YES (8 of 11 types; MODU/Cube rule sets unpublished)
  Musicom path: DONE — `sound/generators/multi_playhead_seq.py` (**SP-164**)

- **Freqport FreqLift — 2-band upward/downward dynamics + tube drive** (soundonsound.com, 2026-11-17)
  Tech: Linear-phase crossover into low/high bands, each with Uplift (upward dynamics — raises material *below* threshold), Tube Drive saturation, and Downlift (downward dynamics), plus attack/release/knee and Tilt/Bias shaping of the distortion; optional hand-off to outboard FT1 tube hardware. Upward compression is the technique worth having: it lifts sustain without touching transients.
  Replicable: YES
  Musicom path: DONE — `sound/effects/upward_dynamics.py` (**SP-165**)

- **Eventide SplitEQ 2** (soundonsound.com, 2026-11-16)
  Tech: Patented Structural Split separates a source into transient and tonal elements, each with its own EQ curve, per-band compression/expansion, independent per-band panning and per-channel settings; new unmask tools compare instances to show competing frequency ranges.
  Replicable: YES (split implemented as differential envelope decomposition, which is the published Sines+Transients family — not the patent's exact internals)
  Musicom path: DONE — `sound/effects/structural_split_eq.py` (**SP-166**)

- **Drumlabooh 14.0.0 — free procedural drum machine** (synthtopia.com, 2026-11-18)
  Tech: Adds a formula-based procedural synthesis engine beside the sampler: drum kits are built from generator modules described by formulas rather than fixed oscillator types, so a kick's pitch/amp/cutoff envelopes are expressions over time. New "Live" control injects per-hit variation into static one-shots; effects order is filters → Live → analog saturator.
  Replicable: YES
  Musicom path: DONE — `sound/generators/formula_drumkit.py` (**SP-167**)

## PARTIAL notes (what is missing, and why no code)

1. **DW-303 coefficient fitting** — the product's selling point is a model fitted to the vendor's own hardware measurements per stage (resonance, accent, slide). We implemented the published *topology* (curved saw, tanh-per-stage ladder with soft-clipped feedback, accent doing VCA+resonance+env simultaneously, 4× oversampling) and proved the quality modes differ measurably in aliasing, but we do **not** claim unit-accurate component values. This is an upgrade of the 2026-11-16 PARTIAL verdict, scoped honestly.
2. **OR-70 macro mapping** — eight module types all exist; the single MORPH knob's mapping curves (density/blur/feedback/shimmer coupled) and MUTATE are unpublished.
3. **phase8 companion** — acoustic transducer instrument; only the editor's sequencer semantics are replicable, and those are already covered.
4. **Laniakea Pro** — no new algorithm; hardware integration + per-voice LPG tuning.
5. **Manley Ecliptic** — parallel band topology trivial; analog colour curves proprietary.
6. **Fragment / Blöcks / Path / miniFM / RipX 9 / Maestro Brass / SynthMaker** — UI-topology variation, patented analysis, proprietary ML weights, unpublished synthesis basis, or analogue model detail respectively.
