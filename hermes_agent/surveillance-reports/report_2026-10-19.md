## Items (one per gear finding)

- **Cableguys TimeStop** (soundonsound.com, 2026-10-15)
  Tech: Tape-stop effect with an automatable speed/depth curve drawn as DAW automation instead of fixed bar lengths. Three timing modes: Classic (playback rate ramps 1.0→~0 while read phase accumulates — pitch and time drop together, vinyl-record stop), Modern (pitch drops WITHOUT changing timing; grains are windowed at time-aligned positions while each grain is resampled internally by the instantaneous rate — the source stays beat-locked; Cableguys claim a first for the category), Loop (captures a slice at the trigger point and retriggers it as a stutter while the central rate curve is applied to the repeated slice).
  Replicable: YES
  Musicom path: **DONE** — `sound/effects/tape_stop.py` (SP-109: `TapeStop`, `default_rate_curve`) — Classic = cumulative-phase resample under a rate curve (exponential default); Modern = time-aligned overlap-add grains with per-grain internal resample (zero time-stretch); Loop = capture+retrigger with rate ramp; gain-compensated; mono/stereo.

- **Baby Audio HyperWarp** (soundonsound.com, 2026-10-07)
  Tech: Granular time-bending effect on a granular engine: incoming signal broken into micro-sampled grains reassembled under one of seven per-grain "sonic imprint" profiles — Clean Warp, Flange Warp, Degrade Warp, Filter Spam, Harmo-Nicer, Fauxcoder, Lo-Fizzly. A graph-based step sequencer lets the user "draw in" speed shifts, stutter steps and direction changes (glitchy rhythms to fluid time-warp motion). Eight controls + sequencer, one-click random patches (generate).
  Replicable: YES
  Musicom path: **DONE** — `sound/effects/hyperwarp_granular.py` (SP-110: `HyperWarpGranular`, `PROFILES`) — 16-step drawable graph with speed/direction/size/pitch/filter lanes, tempo-synced on a 1/16 grid at BPM; grains processed per-profile: clean (plain windows), flange (short modulated comb), degrade (per-grain bit reduction), filter_spam (per-grain one-pole, random cutoff), harmo_nicer (harmonized copies), fauxcoder (comb bank tuned to grain pitch), lo_fizzly (zero-order-hold decimation); seeded one-click random-patch generator.

- **Oddment ODD-1 / ODD-1v** (synthtopia.com, 2026-10-18)
  Tech: Compact hardware instrument + plugin sharing a "microsonic engine": granular processing with samples/incoming audio as raw material. Two independent layers, each with FOUR playheads; per-playhead independent pitch, speed and TIME PATH (read position moves forward, backward, or FREEZE — windowing continues at a fixed position for spectral/sustain textures); grain spacing/size morphs smooth pitched playback → fragmented rhythmic textures; frequency-selective filter applied to individual grains; binaural spatial processing. Three modes: SYNTH (instrument building from samples), LIVE (60-second rolling buffer turns incoming audio into a playable instrument), LOOPS (record separate loops with independent lengths, speeds, tuning while keeping them synchronized). Per-layer: two multimode filters, saturation, echo.
  Replicable: YES
  Musicom path: **DONE** — `sound/synthesis/odd1_engine.py` (SP-111: `Odd1Microsonic`, `Playhead`, `RollingBuffer`) — 2 layers × 4 playheads; TIME PATH forward/backward/freeze per playhead; independent pitch (internal resample) and read speed; grain size/spacing controls; per-grain one-pole frequency-selective filter; SYNTH mode from buffer, LIVE mode via 60 s ring buffer (`capture()`), LOOPS mode with phase-locked scheduling (loops retrigger on the shared bar grid → synchronized independent loops). Binaural/pan per playhead reduced to a placement parameter (full HRTF not replicated).

- **Forma Labs Filament 1.2** (soundonsound.com, 2026-10-16)
  Tech: Real-time MIDI orchestration host: up to 64 AU/VST3 instruments hosted in a single DAW track with MIDI routing, voice allocation, clips, arpeggiators, keyswitch management and mixer states. Version 1.2 adds MPE support, **Auto Divisi** (automatically distribute chord notes across instrument parts), Host Mode, **Note-off Revoice** (choose whether releasing a key redistributes the remaining notes), matrix mute/solo, routing highlights.
  Replicable: YES
  Musicom path: **DONE** — `sound/generators/auto_divisi.py` (SP-112: `AutoDivisi`) — chord-note→part assignment with per-part ranges, workload balancing (no part overstuffed), minimal-motion voice-leading coupled to the previous assignment, nearest-range fallback, unison doublings for duplicate pitches; `revoice(held_notes)` re-distributes surviving notes on key release (Filament's Note-off Revoice). Pure MIDI-level logic, no audio DSP needed.

- **Shear Electronics Relic** (synthtopia.com, 2026-10-18)
  Tech: Eight-voice discrete-analog polyphonic synth: 2 SEM-topology VCOs per voice (16 oscillators total), 7 discrete VCAs/voice (LM13700), 4 envelopes (delay-attack-hold-decay-sustain-release), 4 LFOs × 8 waveforms, 4-part multitimbrality, 512 programs × 4 patches. Core DSP novelty: the **Supervariable VCF** — a four-dimensional filter (cutoff, resonance, bandwidth, filter profile) whose profile can continuously sweep between two-pole high-pass, notch and low-pass responses (voltage-controlled filter character); modern modes add band-pass, X-filter, and two-/three-/four-pole low-pass.
  Replicable: PARTIAL → YES (Supervariable VCF component only)
  Musicom path: Hardware (voice cores/VCAs/multitimbral) not replicable. **VCF replicated** → **DONE** — `sound/effects/supervariable_filter.py` (SP-113: `SuperVariableFilter`) — SVF core computing LP/BP/HP/notch simultaneously; `profile` ∈ [-1,1] continuously morphs HP↔notch↔LP by overlapping response blend; `bandwidth` bleeds BP in to widen the resonant/notch region; `order` 2/3/4 cascades LP sections; modes classic/bp/x/lp24; `profile_mod` vector = the "voltage-controlled filter profile" (modulate character, not just cutoff).

- **Sequential Take 5 Unofficial Editor** (synthtopia.com, 2026-10-16)
  Tech: $35 patch editor by Voidcontrol MIDI: full DAW automation of every Take 5 parameter, 16-slot modulation matrix at a glance (20 sources × 56 destinations, per-slot enable, dot indicator when a modulator points at a control), 64-step polyphonic sequencer (row per voice + velocity lane, step/free record, draw/tie/transpose), A/B snapshots with an automatable **morph** slider, SysEx import/export at program/bank/library scope, init/randomize.
  Replicable: PARTIAL → YES (mod matrix + A/B morph component only)
  Musicom path: 64-step poly seq already covered by `poly_arp_seq.py` (SP-108); editor UI/SysEx not replicable. **Mod matrix + morph replicated** → **DONE** — `sound/modular/mod_matrix.py` (SP-114: `ModMatrix`, `MOD_SOURCES`, `MOD_DESTINATIONS`, `morph`) — 16 slots × 20 sources (LFOs, envelopes, aftertouch/velocity/modwheel/breath/pitchbend, note number, S&H, noise, seq step, macros, gate) × 56 named destinations; per-slot amount + enable; uni/bipolar-aware summing with clip; seeded deterministic sources; A/B `snapshot()` + `morph(a, b, t)` slider (amount crossfade for same routing, per-slot crossfade for changed routing).
