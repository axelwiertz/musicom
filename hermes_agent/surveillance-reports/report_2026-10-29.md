## Items (one per gear finding)

- **Push and Groove MICRONIX** (synthtopia.com, 2026-10-28)
  Tech: Free monosynth built on the open-source (MIT) Mutable Instruments Plaits DSP: 24 synthesis models (virtual analog, FM, wavetable, granular, physical modeling, percussion), each exposing the three Plaits macro controls (Harmonics/Timbre/Morph) with model-specific labels; OUT/AUX blend, 5 LFO waveforms (free-running or tempo-synced), 4-row modulation matrix (LFO/env/velocity/aftertouch/mod-wheel/keytrack sources), ADSR or Plaits-style low-pass-gate envelope (Decay + Color), mono retrigger/legato, glide, randomize.
  Replicable: YES (algorithmic core; clean-room re-implementation of the model families — the MIT code is public but we write our own, not a copy)
  Musicom path: `sound/synthesis/plaits_models.py` — **SP-132** (implemented)

- **Cineol-X 224** (synthtopia.com, 2026-10-27)
  Tech: Open-source project porting the classic Lexicon 224 digital reverb to desktop plugins (AU/VST3) and the Daisy embedded DSP platform; BYO-ROM (no copyrighted firmware); six programs based on the original 224; controls for bass/mid/treble decay, pre-delay, diffusion, modulation enhancement, and a continuously adjustable "Dirt" parameter for the converter-filter character; optional spillover between algorithm changes; v1.0Alpha adds DSP-clock-rate and converter-filter controls.
  Replicable: YES (diffuse delay-network topology — the 224's structure is the well-known all-pass diffuser + cross-coupled delay line network; implemented Dattorro-style, no ROM/firmware copied)
  Musicom path: `sound/effects/lexicon_224_reverb.py` — **SP-133** (implemented)

- **Morphor ECHON 6** (musictech.com product page, 2026-10-28; reviewed July 2026)
  Tech: Six-voice analogue polyphonic synthesizer — "world's first polyphonic analogue synth powered by BBD resonators": each voice is an analogue exciter driving a bucket-brigade-device (BBD) delay line used as a *tuned resonator* (the clock rate sets the pitch); 9×32 modulation matrix, multi-timbral operation, screen-free design, DIN + USB-C MIDI.
  Replicable: YES (BBD-resonator voice logic; the hardware exciter circuits and 9×32 matrix are not replicated)
  Musicom path: `sound/synthesis/bbd_resonator.py` — **SP-134** (implemented)

- **Massive XL** (musictech.com, 2026-10-28)
  Tech: Native Instruments' next-gen flagship soft synth (first major release under InMusic): 100+ new wavetables, a Preset Generator (converts an audio reference into a playable/editable patch), stem separation, a Mutator (patch variations by similarity), revamped modulation environment.
  Replicable: PARTIAL — wavetable scanning core already covered; Preset Generator/stem separation/Mutator need proprietary ML audio analysis (source separation + similarity search) which we cannot fake.
  Musicom path: covered by `spectral_wavetable.py` + `waveshaper_voice.py` (SP-120). No new code.

- **Erica Synths Resonant Filterbank** (soundonsound.com review, Oct-2026)
  Tech: Analogue stereo 10-band fixed-frequency band-pass filterbank (29 Hz–11 kHz): per-band boost/cut, per-band resonance with bipolar (polarity-invertible) feedback, a main feedback loop summing all feedback-enabled bands back into the input, stereo Spread, Filter mode emulating LP/HP/BP/notch by automating the 10 bands, self-oscillation for drone use, LFO/envelope-follower modulation, MIDI CC.
  Replicable: YES (algorithmic core) — **already DONE** in a prior scan: `sound/effects/resonant_filterbank.py` (SP-118). No new code.

- **Newfangled Audio Fixate:Midrange** (soundonsound.com review, Oct/Nov-2026)
  Tech: Resonance-taming / de-mudding plug-in (Soothe/Gullfoss/Curves Equator family) focused on the midrange "battlefield": psychoacoustic-model analysis, Demud/Dethin/Dehonk/Denasal/Deharsh resonance bands + Spectral Balance, mono→stereo→Mid-Sides width, Analyse/Fix workflow.
  Replicable: PARTIAL (classic de-resonator; perception-tuned analysis proprietary) — **already DONE** in a prior scan: `sound/effects/spectral_resonance_suppressor.py` (SP-119). No new code.
