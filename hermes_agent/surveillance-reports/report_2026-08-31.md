## Items (one per gear finding)

- **Asterism** (synthtopia.com, 2026-08-28)
  Tech: Free WebAudio drum machine with advanced sequencing. Replicated logic: **parameter locking** — each step can override named track params (pitch/decay/cutoff/velocity) independent of the track base value; **ratcheting** — a step fires N sub-division bursts (2..4); **randomization** — a track-level randomize rolls every unlocked param within a range while per-param freeze/unlock leaves chosen params untouched.
  Replicable: YES
  Musicom path: sound/generators/param_lock_seq.py (`ParamLockSequencer`)

- **Cherry Audio Memorymode 2** (synthtopia.com, 2026-08-29)
  Tech: Software expansion of the Moog Memorymoog. Replicated logic: per-voice **3 stacked oscillators** with two detune strategies — `unison` (narrow symmetric cents) and `whole_tone` (oscillators locked to −/0/+ a major 2nd = 200 cents, the Memorymoog signature cluster); per-osc saw/pulse/triangle level mix; cascaded 4-pole lowpass with resonance feedback; **3/6/9-voice doubling** where each stacked voice gets a small per-voice detune so doubled voices chorus.
  Replicable: YES
  Musicom path: sound/synthesis/memorymoog_synth.py (`MemorymoogVoice`)

- **Bitwig Studio 6.1 Sampler** (soundonsound.com, 2026-08)
  Tech: Major sampler overhaul. Replicated logic: **auto tempo** via autocorrelation of the RMS energy envelope (period → BPM); **auto pitch** via waveform autocorrelation (lag → fundamental Hz); **auto slicing** via spectral-flux onset detection (frame-wise magnitude delta, local maxima above threshold); **play modes** per slice — oneshot/forward, reverse, loop, pingpong — with per-slice rate (pitch shift via resample); pad-style **slice grid** sequencing.
  Replicable: YES
  Musicom path: sound/generators/sample_slicer.py (`SampleSlicer`, `Slice`, `auto_tempo`, `auto_pitch`)

- **Arturia Pure Sub** (soundonsound.com, 2026-08)
  Tech: Dedicated sub-bass synth: sine/saw/square osc + sub-oscillator + lowpass + drive/saturation for hard-hitting modern bass.
  Replicable: PARTIAL

- **Ravine DSP Inter::State** (soundonsound.com, 2026-08)
