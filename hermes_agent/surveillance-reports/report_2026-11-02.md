## Items (one per gear finding)

- **WMD Modbox MKII** (synthtopia.com, 2026-11-01)
  Tech: Compact Eurorack multifunction modulation module. Three-Phase LFO with three related outputs and three modes — Phase Offset (fixed phase relationships), Phase Modulation (cascading phase distortion: out2 modulated by out1, out3 by out2), Frequency Spread (out2 up to 8× base, out3 down to 1/8×); continuous saw→sine→triangle→ramp waveform morph; 1V/octave tracking and audio-rate operation. Variable-shape Skew LFO (slope control + exponential→linear→logarithmic shape curve). Digital S&H with Sample & Hold, Track & Hold and Turing Machine modes (1–32-sample loop, probability decides new-value-vs-repeat, reversible). Analog white noise normalled into the S&H input; skew pulse normalled into the S&H trigger. Clock sync ratios 1:512 (slow division) to 4:1 (multiplication).
  Replicable: YES (pure CV/DSP logic; hardware/panel/firmware not replicated)
  Musicom path: sound/modular/modbox_cv.py — SP-135

- **Rapid Flow drumGRID** (soundonsound.com, 2026-10-30)
  Tech: Drum virtual instrument: patterns up to 128 steps (straight/triplet/dotted), Euclidean mode beside the grid, probability per step; each step carries velocity, pan, shift, probability, filter, resonance, bit rate and stretch drawn in lanes; seven shuffle modes inspired by classic drum machines, per-track time shift ±64 ms, repeats/rolls with own interval/shape/curve; every lane an 8-slot sampler with Layer/Random/Cycle/Velocity/Morph play modes, choke groups (closed hat cuts open hat), amp/filter ADSR. 1000+ samples recorded through API/SSL/Neve/RND chains (MFB Tanzbär, Vermona DRM1, Cwejman BLD, Nord Drum 3P, 8RAW8, 606 now; TR-909, Rytm MKII, Perkons coming).
  Replicable: YES (sequencing + per-step lane logic; proprietary sample library + GUI not replicated)
  Musicom path: sound/generators/drum_grid.py — SP-136

- **BangZilla Wave Theory** (soundonsound.com, 2026-10-30)
  Tech: MIDI plug-in (with Boxed Ear) that turns the shape of an imported waveform into evolving melodic lines: 100+ built-in wavetables or user imports (reads Serum/Vital .wav tables), four parallel sequencer lanes each with own length/speed, central key/scale quantiser that can follow the chords you play, note probability/timing controls, 16 memory slots. Sends MIDI not audio (negligible CPU, drives any synth).
  Replicable: YES (waveform→pitch mapping + scale quantisation + lane sequencing; GUI/16-slot capture not replicated)
  Musicom path: sound/generators/wave_melody.py — SP-137

- **Art DSP Canvas 2.0** (musictech.com, 2026-10-28)
  Tech: Visual mixing plugin: tracks as movable "blobs" in a virtual 3D room — stereo position → left/right, frequency content → vertical, volume → forward/back depth; **spectral sidechaining** to create space between competing tracks; built-in EQ editor; reverb visualised in the room; one-click whole-track mixing templates.
  Replicable: YES (spectral sidechain DSP + blob analytics; 3D GUI/HRTF/room model not replicated) — previous 2026-10-29 scan flagged PARTIAL (spatial only); spectral sidechain core now implemented.
  Musicom path: sound/effects/spectral_sidechain.py — SP-138

- **Expressive E Noisy 2.6** (soundonsound.com review, Nov 2026 issue)
  Tech: "Noise through resonance" synth: a noise source with 26 types (white → near-naturalistic 'frying' and 'rainforest') excites up to three resonators — now 3 VA oscillators, 2 FM oscillators, a complex harmonic source, a wavetable-like 'wave map', and 4 acoustic models (percussion/bells) — each with pitch offsets and separate glide amounts; multimode filter (5 modes, 12/24 dB), soft clipper output, two identical layers, 8-note poly. MPE expression bus (pressure/aftertouch/velocity + attack-decay) replaces normal ADSR.
  Replicable: YES (noise-exciter→resonator architecture; 26-type library, MPE hardware, effect blocks not replicated)
  Musicom path: sound/synthesis/noise_resonator.py — SP-139

- **Waldorf Crema** (synthtopia.com, 2026-10-31 review + 2026-10-30 announcement)
  Tech: Compact polyphonic string & pad synth built on the Streichfett architecture. Texture engine: 24 sound types combining string-machine tones, wavetables and FM; Streichfett ensemble processing. Lines engine: 8-voice VA with two detunable saw/pulse oscillators, vibrato, stereo tremolo, PWM. Flavour control adds subtle pitch/waveform-position variation; dual effects (serial/parallel) + dedicated shimmer reverb; MPE; 360 preset slots.
  Replicable: YES (string-ensemble + VA engine DSP; 130-sound library, hardware not replicated)
  Musicom path: sound/synthesis/string_ensemble.py — SP-140

- **Warsaw Wave Revolt + NI Massive XL (Mutator/Randomiser/Morpher)** (synthtopia.com 2026-10-30 / musictech.com 2026-10-28)
  Tech: Revolt is a patchable soft synth (4 osc slots, 8 mod slots, 2 multimode filters, 4 reorderable FX slots) with controlled patch randomization: selectable parameters, excluded settings, randomization strength, parameter groups. Massive XL adds a Mutator (similarity-aware patch variations), a Randomiser that scrambles individual modules while leaving favourites untouched, and Morpher/Animator (performed, lockable, transferable movement).
  Replicable: YES (patch-mutation logic; Massive XL Preset Generator + stem separation need proprietary ML — see PARTIAL note)
  Musicom path: sound/modular/patch_mutator.py — SP-141

- **MAP Audio MFX** (synthtopia.com, 2026-10-30)

  Replicable: PARTIAL — cable-routing topology (serial/parallel/feedback w/ level-on-cable) is replicable and overlaps sound/modular/graph.py (node-graph DSP); the 34-effect catalog + GUI are product scope. No new code this scan.

  Replicable: PARTIAL — song/scene/track/pattern hierarchy + fill/gang/sculpt ops are replicable as a scene-arranger generator (would complement polymetric_grid SP-078 / chord_arranger SP-115); GM engine + hardware I/O not replicable. No new code this scan.
