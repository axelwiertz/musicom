## Items (one per gear finding)

- **FAC Gravity** (SoundOnSound, 2026-10-15)
  Tech: Frequency-shifting modulation AUv3 plugin. Two processing modes — stereo (independent L/R shift tied by a Ratio parameter) and mono (quadrature processing for stereo widening from mono source). Uses complex single-sideband modulation to linearly translate the spectrum in Hz (not multiplicatively like pitch shifting), producing inharmonic metallic/phasing/chorus effects. Spiral feedback path combines configurable delay, diffusion blur (1-pole LP), and low/high shelving filters for self-oscillation. LFO + envelope follower modulation matrix. Tempo-sync and MIDI-triggered shift modes.
  Replicable: YES
  Musicom path: sound/effects/frequency_shifter.py (SP-106)

- **Modbap Fidelity Theory** (SoundOnSound, 2026-10-13)
  Tech: Character lo-fi effect plug-in from Eurorack maker Modbap. Single macro control simultaneously adjusts sample rate and word length across a coordinated range (48kHz/6-bit through 6kHz/16-bit). Two converter voicings: Iron (presence boost at ~4kHz with gentle drive) and Worn (low-mid emphasis, softened highs via 2-pole LP, asymmetric saturation with different positive/negative gain curves). Ring mode creates inharmonic metallic texture through aliasing foldover. All parameter changes are smoothed and crossfaded for performance-safe sweeping.
  Replicable: YES
  Musicom path: sound/effects/bit_crusher.py (SP-107)

- **Prophet Rev4 Unofficial Firmware Mod** (Synthtopia, 2026-10-13)
  Tech: Free MIT-licensed firmware patch for Sequential Prophet-5/10 Rev4. Adds a polyphonic arpeggiator (Up/Down/UpDown/Random/Assign modes, 1-4 octave range, 40-300 BPM, tap-tempo, MIDI clock sync, dotted/triplet/swing divisions, hold latch with re-latch) and a polyphonic step sequencer (512 steps, chords up to 10 notes with velocity recording, rests + ties, forward/backward/pendulum playback, keyboard transpose, patch-level memory). Runs on existing hardware via browser-based SysEx patcher.
  Replicable: YES
  Musicom path: sound/generators/poly_arp_seq.py (SP-108)

- **Model-TG — Elektron Model:Cycles Firmware Mod** (Synthtopia, 2026-10-12)
  Tech: Free open-source firmware mod adding a full sampler machine to the Model:Cycles. Seven playback modes (One shot, Loop, Slice, Granular, Stretch, Pluck, Wave). Per-pattern sample assignment/resampling, reverse, waveform view. Slice by equal size/transient detection/manual chopping. Performance page with beat-repeat and 12 master FX. Attack/Filter/Resonance on all stock machines. Slide trigs for glide between p-locked parameters. Scale Lock and CPU optimizations.
  Replicable: PARTIAL — individual engines (granular, slicing) covered by existing modules. Beat-repeat + 12 master FX + slide trigs replicable but hardware firmware + groovebox integration not fully replicable.

- **FoMni — FM-1 Omnichord Firmware** (Synthtopia, 2026-10-12)
  Tech: Free open-source firmware for M-VAVE FM-1 turning it into a Suzuki Omnichord-style chord harp. Pick chord on black keys, strum white keys. Combines organ-like chord, bass, and OM-84 ten-rhythm patterns.
  Replicable: PARTIAL — chord-harp concept (chord+bass+rhythm strum) replicable via harmony_writer.py + scale_quantizer.py + polyrhythm.py, but Omnichord-specific features + hardware = not fully replicable.

- **Olydian VC-01 Voicecrafter** (Synthtopia, 2026-10-11)
  Tech: Hardware vocal synthesizer: formant synthesis engine + consonant-vowel sampling engine. 380 syllables, 6-voice polyphony, 20+ sample banks, per-engine effects, global vibrato/reverb/3 delay types, 2 LFOs, pitch bend, portamento, 3-octave mechanical keyboard.
  Replicable: PARTIAL — formant synthesis = formant_voice.py (SP-036). CV sampling engine + 380-syllable bank = sample content, hardware integration not replicable.

- **AnalogFX LARYNX** (MusicTech, 2026-10-07)
  Tech: Hardware analog synth inspired by Synton Syrinx. 2×CEM3340 VCOs + sub-osc + noise. Unique triple-filter formant architecture: PEAK1, PEAK2, and LPF in combination for speech-like timbres. 16 pre-programmed human voice formants. 5-voice chord mode, stereo delay, 16-step sequencer, arpeggiator, aftertouch keyboard. 50-unit limited run.
  Replicable: PARTIAL — triple-peak formant filter concept replicable. Formant coverage via vowel_filter.py + formant_voice.py. Hardware + CEM3340 + limited run not replicable.

- **Imaginando Colapso** (MusicTech, 2026-10-10)
  Tech: Atomic synthesizer based on Heisenberg Uncertainty Principle. Uses emission spectra from 22 periodic table elements as oscillator timbres. Three-stage architecture: additive (16 partials per oscillator) → granular (pitch-synchronous grains) → subtractive (filter). 8 voices × 3 oscillators, Poly/Mono/Unison with detune/glide/legato. 4 drawable LFOs, 4 drawable envelopes, 4 macros with polyphonic aftertouch. 2 insert + 1 send effects + bus compressor.
  Replicable: PARTIAL — emission-spectrum→oscillator concept replicable (known spectral lines). Each stage covered individually (additive.py, granular.py, filter.py). Integrated 3-stage architecture + 22-element spectral library = significant new content.

- **Bubblegum** (MusicTech, 2026-10-15)
  Tech: Free pitch-editing plugin with polyphonic note detection. Graphical piano-roll-style interface. Global pitch + formant controls, quantize to nearest semitone. 6 editing modes: Main, Vibrato, Drift, Slide, Volume, Formant. Works with polyphonic material (individual notes within chords).
  Replicable: PARTIAL — pitch detection + TD-PSOLA/formant manipulation via phase_vocoder.py (SP-026). Polyphonic note separation is non-trivial DSP requiring source separation or multi-pitch tracking.

- **Idle Foundry CA-72** (MusicTech/Synthtopia, 2026-10-12)

  Replicable: PARTIAL — circuit-modelling DSP not replicable without netlists. Subtractive core covered by mono_synth.py + memorymoog_synth.py. No new code.

## PARTIAL Notes

- Model-TG: 7 playback modes conceptually covered by granular.py + sample_slicer.py; beat-repeat + 12 master FX + slide trigs + Scale Lock replicable as new DSP but not implemented in this scan due to scope.
- AnalogFX LARYNX triple-formant filter: triple-peak (PEAK1 + PEAK2 + LPF) vocal tract filter is a distinct architecture from existing vowel_filter.py (5-band formant). Could be added as sound/effects/triple_formant_filter.py in a future scan.
- Imaginando Colapso emission-spectrum oscillator: each element's spectral lines are well-known physics (H, He, C, N, O, Fe, etc.) and could be encoded as harmonic templates. Not implemented (22 elements × 3 oscillators = significant data entry).
- Bubblegum polyphonic pitch detection: non-trivial. Phase vocoder resynthesis (SP-026) handles monophonic pitch shift; Multi-pitch tracking + source separation would be needed for polyphonic editing.
